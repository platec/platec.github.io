序列化与反序列化 ​

Storage.serialize() / Storage.deserialize() 负责场景图的 JSON 往返。设计目标：序列化结果只含无歧义的最小数据，默认值不入库。

序列化 ​

ts
const json = storage.serialize();               // 对象
const text = JSON.stringify(json, null, 2);     // 用于保存 / 导出

输出结构：

jsonc
{
  "elements": [
    {
      "id": 1,
      "type": "Shape",           // Shape | Text | Image | Polyline | Connector | Group | Component | Clip | Restore
      "props": {                 // 结构化属性（仅非默认值；简化后的 setter 语义）
        "x": 60, "y": 140,
        "width": 120, "height": 60
      },
      "styles": {                // 仅实例级样式，默认值不写入
        "background": "#d8eee9"
      },
      "attrs": {}                // 业务属性（空对象省略）
    }
  ],
  "props": {                     // storage 级属性（默认项省略）
    "background": "#fff"
  },
  "attrs": {},
  "contentRect": { "x": 0, "y": 0, "width": 100, "height": 100 }
}

props 序列化细节 ​

内容格式
位置props.x / props.y（替代 position）
锚点props.anchor = { x: 0.5, y: 0.5 }
滤镜props.filters 为内置滤镜名数组
Connectorprops.start / props.end = { id: nodeId }
宿主吸附props.host = { id: nodeId }（Node.setHost 后写入）
Group 子节点props.parent = { id } 或 Group 的 props.children
动画为空时不写 animations；interactive 仅 true 时写入
精度几何数值保留 5 位小数
ts
// 检查一段代码如何写入/读取 props：以 Connector 为例
const connector = new Connector();
connector.setStart(nodeA);
connector.setEnd(nodeB);
storage.add(connector);

const json = storage.serialize();
const c = json.elements.find((e: any) => e.type === 'Connector');
console.log(c.props.start);      // { id: nodeA.getId() }
console.log(c.props.end);        // { id: nodeB.getId() }

// 再放回：deserialize 会把 { id } 解析回元素实例引用
storage.deserialize(JSON.stringify(json));   // 或直接传 json 对象

默认值压缩 ​

序列化按「只含无歧义的最小数据」压缩：props / styles / attrs 中等于默认值的条目一律省略（含 position 为 {x:0,y:0}、anchor 为 {x:0.5,y:0.5}、visible / opacity 为 1 等），空对象整体删除，因此最小图纸可能形如 {"elements":[{"id":1,"type":"Shape"}]}。deserialize 时按类型默认值补齐，往返结果一致。

运行配置 attrs ​

fitContent / zoomable / pannable 等运行 / 预览配置存放于顶层 attrs，随图纸 JSON 往返：

jsonc
"attrs": {
  "fitContent": true,   // 只读预览打开时自动适配内容
  "zoomable": false,    // 锁定视口缩放
  "pannable": false     // 锁定视口平移
}

见 API 参考：Storage 属性。

反序列化 ​

ts
storage.deserialize(json);         // 接受对象或 JSON 字符串（编辑器常用）
storage.deserialize(undefined);    // 清空并重置

流程：发出 beforeDeserialize → 解绑旧元素 → 批量 setAttr / storage 属性 setter → 用过 classMap 反射实例化元素（new Class + setId）→ 应用 setter → element.s(styles) → element.a(attrs) → 恢复父子关系 → 发出 deserialize 完成事件。

自定义元素类型 ​

ts
import { registerElementType } from '@leaf-plus/core';

class MyCustomShape extends Shape { /* ... */ }
registerElementType('MyCustomShape', MyCustomShape);

// 此后该类型可正常序列化 / 反序列化往返

内容包围盒 ​

ts
storage.recalculateContentRect();        // 由元素包围盒推导
storage.getContentRect();
storage.setContentRect({ x: 0, y: 0, width: 800, height: 600 });
  • recalculateContentRect({ silent: true }) 只更新值不触发重绘。
  • 导出 PNG 时按背景 bounds / 元素渲染边界取导出范围（View.toPNG 优先取背景 bounds，其次内容包围盒），不会写回 storage 的 contentRect。

事件 ​

ts
storage.on('storageChange', (arg) => {
  // arg.type: beforeDeserialize | deserialize | add | remove | ...
});

编辑器实践 ​

图形编辑器（在线体验，源码 packages/editor）的做法（可参考）：

ts
// 保存
storage.recalculateContentRect({ silent: true });
const data = storage.serialize();
const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
// 下载...

// 加载
storage.deserialize(JSON.parse(text));
const view = new View(storage);
view.fitContent();

图标（矢量符号）走 serializeSymbolDocument，额外携带 width / height / attachPoints / cacheRule / fitSize / bind 等元信息。
