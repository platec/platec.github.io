导出与独立绘制 ​

以下示例统一使用这个下载辅助函数：

ts
function saveBlob(blob: Blob, filename: string) {
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = filename;
  a.click();
  URL.revokeObjectURL(url);
}

导出 PNG ​

View.toPNG() 将当前场景导出为图像：

ts
const blob = await view.toPNG({
  bounds: { x: 0, y: 0, width: 800, height: 600 },  // 世界坐标范围；缺省优先取背景 bounds，其次内容包围盒
  width: 1600,          // 输出宽度（像素），缺省同 bounds 宽度
  height: 1200,         // 输出高度
  quality: 1,           // 0–1（PNG 编码质量）
});
saveBlob(blob, 'scene.png');
  • 导出范围外的元素会被临时豁免剔除，保证范围内内容全部参与渲染。
  • 高清导出以 width/height 缩放像素比重绘。
  • renderHTML 是 DOM 叠加层，不属于 Canvas 像素导出结果；编辑器导出时通过 HtmlOverlay.prepareCapture + html-to-image 单独合并（packages/editor 内部实现）。

导出 SVG ​

View.toSVG() 将当前场景渲染为独立 SVG 文档（返回字符串），矢量文本保持可编辑：

ts
const svg = view.toSVG({
  bounds: { x: -20, y: -20, width: 840, height: 640 },  // 世界坐标范围；缺省优先取背景 bounds，其次内容包围盒
  background: '#ffffff',        // 背景色；缺省取 Storage 背景，null 表示透明
});
saveBlob(new Blob([svg], { type: 'image/svg+xml;charset=utf-8' }), 'scene.svg');
  • 导出为可编辑矢量：文本输出为 <text>（保留字体、对齐、基线，超出 maxWidth 时用 textLength 压缩），渐变 / 图案 / 阴影 / 裁剪写入 <defs> 引用，混合模式通过 mix-blend-mode 保留。
  • 图片资源以内嵌方式写入（data URI 或画布序列化）。
  • 无有效边界（bounds 为空或宽高非正）时抛出错误。
  • 内部由 Canvas 2D 兼容的记录上下文 SVGContext 实现，ViewRenderer 在导出期间临时关闭视口剔除并重置缩放 / 像素比，保证完整绘制。

renderHTML 是 DOM 叠加层，无法用 Canvas 记录器表达；编辑器导出 SVG 时会将该层栅格化为一张透明 PNG 图层嵌入 SVG 末尾（packages/editor 内部实现），保持外观的同时保留普通图元的可编辑矢量。

独立绘制（不依赖 Storage / View） ​

若只需要「画一个图形」到任意 Canvas 上下文，可使用独立绘制函数：

ts
import { drawShapeStandalone, drawTextStandalone, drawPolylineStandalone, drawImageStandalone } from '@leaf-plus/core';

drawShapeStandalone(ctx, 0, 0, 120, 60, {
  shape: 'rect',
  background: '#d8eee9',
  borderColor: '#2a7f72',
  borderWidth: 2,
});
函数绘制
drawShapeStandalone(ctx, x, y, w, h, styles, element?, view?)Shape 路径
drawTextStandalone(...)文本
drawPolylineStandalone(...)折线
drawImageStandalone(...)图片资源
drawStretchImageStandalone(...)拉伸图片（带裁剪）

辅助：resolveDrawStyles(...) 按样式表解析；createBindingHost(...) 构造属性绑定宿主。

资源加载与缓存 ​

ts
import { setImage, getImage, releaseImage, clearImageCache, loadResource, loadResources } from '@leaf-plus/core';

setImage('logo', url);         // 注册资源（URL / SVG 字符串 / data URI）
const img = getImage('logo');  // 获得缓存的 ImageBitmap / HTMLImageElement / 矢量描述
releaseImage('logo');          // 释放（解除引用后资源缓存销毁）

await loadResource(symbolPath);        // 加载矢量符号 / 图片
await loadResources([pathA, pathB]);   // 批量加载（仅接受路径数组）

资源更新后发出 resourceLoaded，View 会自动清缓存并重绘。

HTML 叠加渲染 ​

Image 元素可通过 renderHTML 叠加 DOM：

ts
const el = new Image();
el.setImage('bg.png');
el.s('renderHTML', {           // 样式键方式传入定义
  render: (element) => { ... },
  keys: ['value'],
});
storage.add(el);

ElementStyles['renderHTML'] 的类型声明为序列化字符串（渲染器名或源码），但运行时（resolveHTMLRendererSource）同时支持函数与定义对象形态，el.setRenderHTML(def) 亦可直接传入。

自定义 HTML 渲染器需先全局注册：

ts
import { registerHTMLRenderer } from '@leaf-plus/core';

registerHTMLRenderer('kpi-card', {
  render: (element, view) => {
    const div = document.createElement('div');
    div.innerHTML = '<b>KPI</b>';
    return div;
  },
  update: (dom, element, view) => { /* 键变化时原地更新 DOM */ },
  dispose: (dom) => { dom?.remove(); },   // 宿主回收时释放资源
  keys: ['value'],          // 仅这些 attr 键变化才刷新
  resizeAware: true,        // 元素尺寸变化也刷新
});

无注册渲染器时 renderHTML 也可直接使用 HTML 字符串。DOM 层由 HtmlOverlay 管理，随 View 的变换同步位姿。

标记 / 路径工具 ​

ts
import { registerMarkerType, createPathWalker } from '@leaf-plus/core';

// 工厂返回 Path2D（标记几何中心位于 (0,0)，朝正 X 轴指向路径外侧）
registerMarkerType('my-arrow', (width, height) => {
  const path = new Path2D();
  path.moveTo(width / 2, 0);
  path.lineTo(-width / 2, -height / 2);
  path.closePath();
  return path;
});

// 路径弧长采样（流动线等插件的基础设施）
const walker = createPathWalker(pathGeometry);
const sample = walker.pointAt(50);   // 弧长 50 处 → { x, y, angle }
