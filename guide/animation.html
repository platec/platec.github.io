动画系统 ​

Leaf Plus 提供两层动画能力：Tween 补间系统（通用属性动画）与内置动画效果（图片元素上的循环动画）。

Tween 补间 ​

ts
import { Tween, Easing } from '@leaf-plus/core';

new Tween({ x: 0 }) // target：普通对象
  .to({ x: 100 }, 1000) // 目标属性 + 时长（ms）
  .easing(Easing.cubicOut)
  .onUpdate((obj) => {
    shape.setX(obj.x);
  })
  .start();

完整 API ​

方法说明
to(properties, duration=1000)补间目标（仅 number 属性生效）
easing(fn)缓动函数
delay(ms)延迟启动
repeat(times)重复次数（-1 为无限）
yoyo(true)往返播放
chain(...tweens)串联补间
onStart/onUpdate/onComplete/onStop/onRepeat事件回调
start() / stop() / pause() / resume()控制
isPlaying() / getTarget()查询
ts
new Tween({ opacity: 0.3 })
  .to({ opacity: 1 }, 500)
  .easing(Easing.sineInOut)
  .delay(200) // 启动前等待 200ms
  .repeat(-1) // 无限重复
  .yoyo(true) // 每次往返播放
  .onRepeat((target) => console.log('一轮结束', target))
  .onUpdate((target) => shape.s('opacity', target.opacity))
  .start();
ts
// 第一个完成后接着跑第二个
new Tween({ x: 0 })
  .chain(
    new Tween({ x: 0 }).to({ x: 100 }, 600),
    new Tween({ x: 100 }).to({ x: 0 }, 600),
  )
  .start();

缓动函数 ​

Easing 提供：linear、quadIn/Out/InOut、cubicIn/Out/InOut、quartIn/Out、sineIn/Out/InOut、expoIn/Out、circIn/Out、backIn/Out、bounceIn/Out、elasticOut。

ts
new Tween({ y: 0 })
  .to({ y: 200 }, 1000)
  .easing(Easing.elasticOut) // 弹性出场
  .start();

new Tween({ progress: 0 })
  .to({ progress: 1 }, 800)
  .easing(Easing.cubicInOut) // 缓入缓出
  .onUpdate((p) => progressBar.setWidth(p.progress * 100))
  .start();

动画视口 ​

ts
view.zoomToPoint(1.5, { x: 0, y: 0 }, true); // 第三参数 animate=true
view.panTo(100, 50, true);
view.fitContent(20, true);

View 内部使用 Easing.cubicOut 补间视口（约 300ms）。

内置动画效果 ​

内置动画是带 bind 配置的内置图标。属性面板读写图标 attr，资源内的动画定义通过 attr@ 绑定实时取得参数。

ts
import { createBuiltinAnimationIcon, getBuiltinAnimationParamAttr } from '@leaf-plus/core';

const animImage = createBuiltinAnimationIcon('plasmaAnimation');
animImage.a(getBuiltinAnimationParamAttr('color'), '#55eeff');
animImage.a(getBuiltinAnimationParamAttr('count'), 48);
storage.add(animImage);

Core 内置动画类型只有：commonAnimation（通用动画，旋转 / 呼吸缩放 / 透明度循环，可切换渲染图标或图片）和 plasmaAnimation（等离子体）。Lottie、视频和 WebP 动画由对应插件提供。

  • 动画时长为帧循环，由 View 的 RAF 渲染循环驱动。
  • 重型内置动画（粒子、火焰等）默认在 Worker 图集中离屏渲染：animationRuntime 把动画帧绘制到 Worker 内的图集再回传合成，避免阻塞主线程；Worker 不可用的环境自动回退主线程渲染。可用以下函数控制：
ts
import {
  setAnimationWorkerEnabled,    // 全局开关（默认 true；关闭立即释放全部 Worker）
  isAnimationWorkerEnabled,
  isAnimationWorkerAvailable,   // 指定 View 当前是否真的拿到了 Worker
} from '@leaf-plus/core';

setAnimationWorkerEnabled(false);             // 关闭加速
console.log(isAnimationWorkerAvailable(view)); // 该 View 是否已启用 Worker 图集
  • play: false 会暂停在当前帧，保留已有粒子和视觉状态；重新设为 true 后从该帧继续（暂停期间效果不推进状态，elapsed 不含暂停时长）。
  • 效果可定义 isActive(context) 钩子：返回 false 时效果仍绘制当前帧，但不再请求下一帧（如礼花粒子全部消散后自然停止）；未定义时按持续请求处理。
  • enabled: false 表示禁用该效果；setAnimations([]) 则会删除动画定义并释放运行状态，不用于暂停。
  • 仅调整 play / speed / params 时保留效果运行状态（可暂停 / 续播）；动画槽位或类型变化时才会完整释放重建。
  • 动画效果会随插件系统注册：registerAnimationEffect（见 插件系统）。
  • 运行时参数通过 AnimationBinding 绑定，resolveAnimationValue 可手动解析。

获取动画素材 ​

函数用法
getBuiltinAnimationImageName(type)动画类型 → 内置图片资源名
getBuiltinAnimationImages()全部内置动画图片
isBuiltinAnimationImage(name)判断图片是否内置动画
getBuiltinAnimationType(name)图片 → 动画类型
getAnimationEffect(type) / getAnimationEffectMetas()查询效果定义 / 参数元信息
createBuiltinAnimationDefinition(type)按效果元信息默认值构造 ElementAnimation
createBuiltinAnimationIcon(type, options?)创建由 bind / attr 驱动的内置动画图标
getBuiltinAnimationParamAttr(key)动画参数名 → 图标 attr 名
ts
import {
  isBuiltinAnimationImage,
  createBuiltinAnimationIcon,
  getBuiltinAnimationType,
  getBuiltinAnimationImages,
} from '@leaf-plus/core';

if (!isBuiltinAnimationImage(img.getImage())) return;
const img = createBuiltinAnimationIcon('plasmaAnimation');
console.log(getBuiltinAnimationType(img.getImage())); // 'plasmaAnimation'
console.log(getBuiltinAnimationImages()); // 全部内置动画清单

参数元信息 ​

ts
import { getAnimationEffectMetas } from '@leaf-plus/core';
const metas = getAnimationEffectMetas();
// [{ name: 'fire', parameters: [{ key: 'speed', label: '速度', type: 'number', min, max, step }], ... }]

图形编辑器（packages/editor）属性面板的「动画」配置正是基于这套元信息渲染参数表单。

逐帧驱动 ​

插件动画（如流动线）依赖 PluginContext.requestFrame(view) 持续请求下一帧（详见 插件系统）。

ts
// 插件内自定义逐帧动画
install(context: PluginContext) {
  afterDrawDecorator = {
    afterDraw: ({ ctx, element, view }) => {
      const phase = (Date.now() % 2000) / 2000;   // 0 → 1 往返
      drawPulse(ctx, element.getBoundingBox(), phase);
      context.requestFrame(view);                  // 请求下一帧
    },
  };
}
