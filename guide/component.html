组件（Component） ​

Component 是一个 Node 子类图元，用来渲染一个命名的组件定义。它是矢量符号内部可复用、可被属性驱动（数据绑定）的绘制单元——典型用途是仪表指针、进度环、数字面板这类「结构固定、数值随数据变化」的图形。

与 Group / Image 的区别 ​

类型定位
Group把已存在的多个元素组合成一棵子树，自身不绘制（见 Group）
Image承载整张矢量符号 / 图片，符号内部可以再包含 Component 槽位（见 图元：Image）
Component渲染单个命名组件定义，组件内部字段可声明属性绑定，由承载它的宿主求值

基本用法 ​

ts
import { Component, updateComponent } from '@leaf-plus/core';

// 1) 先把组件定义注册进资源缓存（也可来自加载的矢量符号 JSON）
updateComponent('circleProgressBar', progressBarJson);

// 2) 创建组件图元，绑定到该定义
const gauge = new Component();
gauge.setComponent('circleProgressBar');
gauge.setPosition(80, 60);
gauge.setSize(120, 120);
storage.add(gauge);
方法说明
setComponent(name) / getComponent()绑定 / 读取组件定义名
setSize(w, h) / setWidth(w) / setHeight(h)组件尺寸
prepareRender()渲染前检查：组件定义已在资源缓存中才可绘制

组件定义与更新 ​

组件定义存放在资源缓存中，按名字查找。运行期可动态更新，更新后通知所有 View 重绘：

ts
import { updateComponent, setComponent, getComponent } from '@leaf-plus/core';

updateComponent('circleProgressBar', json);   // 解析并写入缓存 + 触发全局重绘
setComponent('circleProgressBar', parsed);     // 写入已解析的定义（不重解析）
getComponent('circleProgressBar');             // 读取当前定义

组件定义通常来自矢量符号（symbol）JSON：在编辑器里，「组件」是一类独立资源，可放入图标画布并配置属性绑定——组件内部某个字段标记为 { func, value } 绑定表达式，绘制时先对表达式求值，失败或无值则回退到 value。绑定机制与图标一致，详见 图标绑定（该页的示例即使用内置的 circleProgressBar 环形进度条组件）。

属性绑定示例 ​

组件字段的绑定表达式在绘制时求值，数据源来自承载它的宿主属性（attr@ / prop@）：

ts
// 组件定义（简化）：进度值绑定到宿主的 percent 属性
{
  "type": "component",
  "arc": {
    "arcTo": { "func": "attr@percent", "value": 0 }   // 求值失败回退 0
  }
}
ts
gauge.a('percent', 72);   // 改属性即驱动组件重绘

组件的完整可编辑体验（新建、槽位配置、绑定清单）在图形编辑器的「组件」资源页签中，见 图形编辑器。
