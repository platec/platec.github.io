样式系统 ​

ElementStyles 是全局接口（声明于 src/types/globals.ts），插件可以通过 TS 声明合并 扩展样式键（见 插件系统）。

下图汇总本章全部样式键的实时效果（每个卡片一类样式，可缩放/平移查看）：

解析顺序 ​

样式按以下优先级解析（低 → 高）：

  1. 插件默认值（usePlugin 注册的默认值）
  2. 全局默认样式（defaultStyles）
  3. 类型默认样式（defaultStyles.Shape / defaultStyles.Text 等）
  4. 实例样式（el.s({ ... }) 设置）

示例：

ts
import { defineConfig } from '@leaf-plus/core';

// 全局调整默认样式（在创建元素前调用）
defineConfig({
  defaultStyles: {
    Shape: { borderColor: '#334155' },
  },
});

基础用法 ​

ts
shape.s('background', '#d8eee9');   // 单键设置
shape.s({                           // 批量设置
  borderColor: '#2a7f72',
  borderWidth: 2,
  cornerRadius: 6,
});
shape.s('borderColor');             // 读取（解析后的值）

每个图元在 _draw 中通过 _pickStyles(keys) 批量读取样式键，因此 仅影响该图元样式的键 不会触发内部错误。

布局与全屏 ​

三个布局相关样式键作用于 Node：

ts
// 全屏适配：渲染前把节点铺满视口
background.s('fullscreen', 'fill');     // fill 拉伸填满 | uniform 等比完整显示（居中）
logo.s('fullscreen', 'uniform');

// 宿主吸附的布局约束（配合 setHost，见下文「宿主吸附」）
child.setHost(host);
child.s('layoutH', 'left');       // left | right | center | leftright | scale
child.s('layoutV', 'topbottom');  // top | bottom | center | topbottom | scale
  • fullscreen 由渲染管线每帧执行：fill 拉伸填满视口，uniform 按自身宽高比等比完整显示并居中。编辑模式下 fill 不生效（保留原始几何便于编辑），预览 / 运行模式恢复适配；其优先级高于画布级 fitContent 自动适配。
  • layoutH / layoutV 决定吸附节点相对宿主锚点的约束：固定边距（left/right/center/top/bottom）、随宿主拉伸（leftright/topbottom）或等比缩放（scale）。宿主几何变化时自动重算吸附节点的位置与尺寸。

完整语义见 API 参考：Node 宿主吸附、样式配置项。

Shape 样式 ​

ts
shape.s({
  shape: 'rect',          // rect | circle | oval | roundRect | star | pentagram | triangle |
                          // hexagon | pentagon | diamond | rightTriangle | parallelogram |
                          // trapezoid | polygon | arc | nStar | stencil:<name>
  cornerRadius: 8,        // 圆角（roundRect 等）
  polygonSides: 6,        // polygon / nStar 的边数
  arcFrom: 0,             // arc 起止角（弧度）
  arcTo: Math.PI * 2,
  arcClose: true,
  background: '#d8eee9',
  borderColor: '#2a7f72',
  borderWidth: 2,
  borderCap: 'round',     // lineCap
  borderJoin: 'round',    // lineJoin
  fillAfterStroke: false, // 控制填充与描边顺序
  fillRule: 'nonzero',    // 填充规则
});

渐变 ​

ts
shape.s({
  background: '#ffffff',
  gradient: 'linear.north',     // linear.north/south/west/east/northwest/northeast/southwest/southeast
  gradientColor: '#2a7f72',     // 变色终点
  // radial.center、spread.horizontal 等亦可
});

// 渐变 pack（精确控制停靠点，坐标按宽高归一化）
shape.s({
  background: '#ff0',
  gradientPack: ['linear', 0, 0, 1, 1, 0, '#ff0000', 1, '#00ff00'],
});

// 前景图层也支持渐变
shape.s({ foreground: '#f00', foregroundGradient: 'linear.west', foregroundGradientColor: '#00f' });
ts
// 径向渐变（中心 → 边缘）
shape.s({
  background: '#ffffff',
  gradient: 'radial.center',      // 或 radial.north/west/...
  gradientColor: '#38bdf8',
});

// spread 三色对称带（背景 → 渐变 → 背景）
shape.s({
  background: '#fef3c7',
  gradient: 'spread.horizontal',  // 或 spread.vertical/diagonal/antidiagonal/north/...
  gradientColor: '#f97316',
});

// 径向 pack：圆心(0.5,0.5)，半径 0.8（相对 min(w,h)）
shape.s({
  background: '#ffffff',
  gradientPack: ['radial', 0.5, 0.5, 0.8, 0, '#38bdf8', 1, '#0f172a'],
});

Text 样式 ​

注意：文本内容是样式键 text，不是 props。

ts
text.s({
  text: '你好，Leaf Plus！',
  font: '16px arial, sans-serif',     // 亦可分别设置 fontSize/fontWeight/fontStyle/fontFamily
  color: '#333333',
  background: '#ffffff',              // 文本描底
  outlineColor: '#ffffff',            // 描边（outlineWidth）
  align: 'left',                      // left | center | right
  vAlign: 'middle',                   // top | middle | bottom
  vertical: false,                    // 竖排文本
  verticalGap: 0,
  lineHeight: 1.5,
  wrap: false,                        // 自动换行
  textOverflow: 'ellipsis',           // visible | clip | ellipsis
  textPadding: 8,                     // 或 [上, 右, 下, 左]
  letterGap: 0,                       // 字间距
  cornerRadius: 0,
  decoration: 'none',
});

Text 未显式设置宽高时默认 100 × 50（getWidth() / getHeight() 覆写）。

Image 样式 ​

ts
image.s({
  imageStretch: 'uniform',   // fill | uniform | centerUniform | cover | center
  renderHTML: '<div>...</div>', // HTML 叠加内容（见下方）
});

Image 的 props：image（资源名 / URL / data URI）、renderHTML、width / height（未设置时自动从资源固有尺寸同步）。

Polyline / Connector 样式 ​

Polyline 与 Connector 共享描边 / 虚线族：

ts
polyline.s({
  borderColor: '#2C3E50',
  borderWidth: 3,
  borderJoin: 'round',
  dash: [],              // 虚线数组
  dashColor: '#f00',
  dashWidth: 2,
  dashOffset: 0,
  borderPattern: [6, 4],
});

Connector 另有 edgeStyle / 端点标记 / 锚点样式（见 API：Connector）。

过滤与混合 ​

ts
import { Blur, Grayscale } from '@leaf-plus/core';

// 像素滤镜（11 种内置）：必须先通过 filters([...]) 注册滤镜链，
// 再以同名样式键提供参数（如 blur 半径）
shape.filters([Blur, Grayscale]);
shape.s('Blur', 4);                   // 模糊半径（滤镜参数，即同名样式键）
shape.filters(null);                  // 清除滤镜

// 混合模式
shape.s('blendMode', 'multiply');

内置滤镜：Blur、Brightness、Contrast、Grayscale、Glitch、HueRotate、Invert、Saturate、Sepia、Pixelate、Noise。

阴影 ​

ts
shape.s({
  shadow: true,
  shadowColor: 'rgba(0,0,0,0.35)',
  shadowBlur: 12,
  shadowOffsetX: 4,
  shadowOffsetY: 4,
  shadowInset: true,    // 内阴影（离屏合成）
});

像素级命中（pixelPerfect） ​

ts
// 单个元素开启
shape.s('pixelPerfect', true);

// 或全局设置为默认（编辑器即如此配置）
defineConfig({ defaultStyles: { Shape: { pixelPerfect: true } } });

开启后，Shape / Text 的命中从 OBB 几何检测升级为逐像素 alpha 检测（命中成本更高）。内置动画 Image / 自带动画 / renderHTML 元素例外，仍按包围盒命中。

完整的样式键、默认值与取值枚举对照表见 API 参考：样式配置项。

滤镜 / 混合 / 阴影对性能的影响 ​

  • 滤镜与内阴影使用离屏画布按元素缓存。
  • 手绘模式会跳过渐变、立体描边和虚线（按设计如此）。
  • 视口裁剪边界会自动外扩（expandBoundsForRough / expandBoundsForShadow）。
