样式系统 ​

ElementStyles 是全局接口（声明于 src/types/globals.ts），插件可以通过 TS 声明合并 扩展样式键（见 插件系统）。

下图汇总本章全部样式键的实时效果（每个卡片一类样式，可缩放/平移查看）：

解析顺序 ​

样式按以下优先级解析（低 → 高）：

  1. 插件默认值（usePlugin 注册的默认值）
  2. 全局默认样式（defaultStyles）
  3. 类型默认样式（defaultStyles.Shape / defaultStyles.Text 等）
  4. 实例样式（el.s({ ... }) 设置）

示例：

ts
import { defineConfig } from '@leaf-plus/core';

// 全局调整默认样式（在创建元素前调用）
defineConfig({
  defaultStyles: {
    Shape: { borderColor: '#334155' },
  },
});

基础用法 ​

ts
shape.s('background', '#d8eee9');   // 单键设置
shape.s({                           // 批量设置
  borderColor: '#2a7f72',
  borderWidth: 2,
  cornerRadius: 6,
});
shape.s('borderColor');             // 读取（解析后的值）

每个图元在 _draw 中通过 _pickStyles(keys) 批量读取样式键，因此 仅影响该图元样式的键 不会触发内部错误。

布局与全屏 ​

三个布局相关样式键作用于 Node：

ts
// 全屏适配：渲染前把节点铺满视口
background.s('fullscreen', 'fill');     // fill 拉伸填满 | uniform 等比完整显示（居中）
logo.s('fullscreen', 'uniform');

// 宿主吸附的布局约束（配合 setHost，见下文「宿主吸附」）
child.setHost(host);
child.s('layoutH', 'left');       // left | right | center | leftright | scale
child.s('layoutV', 'topbottom');  // top | bottom | center | topbottom | scale
  • fullscreen 由渲染管线每帧执行：fill 拉伸填满视口，uniform 按自身宽高比等比完整显示并居中。编辑模式下 fill 不生效（保留原始几何便于编辑），预览 / 运行模式恢复适配；其优先级高于画布级 fitContent 自动适配。
  • layoutH / layoutV 决定吸附节点相对宿主锚点的约束：固定边距（left/right/center/top/bottom）、随宿主拉伸（leftright/topbottom）或等比缩放（scale）。宿主几何变化时自动重算吸附节点的位置与尺寸。

完整语义见 API 参考：Node 宿主吸附、样式配置项。

滤镜与混合 ​

Leaf Plus 提供两代滤镜 API：

  • 滤镜效果（filterEffects，推荐）：纯 JSON 数据描述，可随图纸序列化，支持 Worker / WebGL 异步加速，内置 35 种效果，可注册自定义效果。
  • 滤镜类（filters，旧版）：滤镜类 + 同名样式键传参，仍受支持（编辑器打开旧图纸时会提示并迁移为滤镜效果）。

滤镜效果（filterEffects） ​

ts
node.filterEffects([
  { type: 'dropShadow', params: { color: '#000000', blur: 12, offsetX: 4, offsetY: 4 } },
  { type: 'blur', params: { radius: 2 } },
]);
node.filterEffects();     // 读取（返回副本）
node.filterEffects(null); // 清除
// 显式形式：node.getFilterEffects() / node.setFilterEffects(effects)

每条效果是一个 FilterDescriptor：

字段类型说明
typestring效果类型（见下表，或 registerFilterEffect 注册的自定义类型）
paramsobject参数（number / string / boolean），缺省取效果默认值
enabledbooleanfalse 时跳过该效果（配置保留）
backend'auto' | 'gpu' | 'worker-cpu' | 'main-cpu'执行后端，默认 auto
  • 滤镜结果按元素缓存为位图，仅描述或内容变化时重算；重效果链自动在 Worker 中异步执行（内部自动选择 WebGL / CPU），轻量链在主线程同步执行，也可用 backend 强制指定。
  • 向外扩展像素的效果（dropShadow、outline、bloom 等）会自动外扩渲染边界，不会被视口裁剪误裁。
  • filterEffects 是纯 JSON，随 storage.serialize() 写入 props.filterEffects 往返。

内置效果（type → 主要参数 / 默认值）：

分类效果
颜色调整brightness、contrast、saturate（amount: 1）；grayscale、sepia、invert（amount: 1）；exposure（amount: 0，2 的幂次曝光）；gamma（amount: 1）；threshold（amount: 0.5 阈值）；hueRotate（degrees: 0）；tint（color + amount，染色）
模糊 / 像素化blur（radius）；pixelate（size: 8）；directionalBlur / motionBlur（radius: 8, angle: 0）
阴影 / 发光dropShadow、outerGlow、innerGlow（color、opacity: 0.75、blur: 8、offsetX/offsetY）
轮廓 / 卷积outline（color、width: 1、opacity）；sharpen / edgeDetect / emboss（amount: 1）
色调分离posterize（levels: 6）；duotone（shadow、highlight、amount）；dither（levels: 4, amount: 1 有序抖动）；lut（source: LUT 图片 URL，size: 16，intensity）
几何变形ripple / wave / swirl（amplitude: 10、frequency: 0.05、centerX/Y: 0.5、radius、angle）；displacementMap（map: 位移图 URL、scaleX/scaleY、channelX: 'r'、channelY: 'g'）；chromaticAberration（offset: 3、angle，色差）
艺术效果glitch（amount: 35、seed: 25、quality: 30、iterations: 20，故障）；vignette（amount: 0.5、radius: 0.75、softness、color，暗角）；bloom（threshold: 0.7、intensity: 1、radius: 8，辉光）；channelMixer（rr…bb 3×3 通道矩阵）

Noise 噪声仅有旧版滤镜类（见下），暂无同名滤镜效果。

自定义效果通过 registerFilterEffect(definition) 注册（CPU 实现 + 可选 GPU 标识 / outset 声明），见 工具函数：滤镜效果注册。

滤镜类（旧版） ​

ts
import { Blur, Grayscale } from '@leaf-plus/core';

// 11 种内置滤镜类：先通过 filters([...]) 注册滤镜链，
// 再以同名样式键提供参数（如 blur 半径）
shape.filters([Blur, Grayscale]);
shape.s('Blur', 4);                   // 模糊半径（滤镜参数，即同名样式键）
shape.filters(null);                  // 清除滤镜

内置滤镜类：Blur、Brightness、Contrast、Grayscale、Glitch、HueRotate、Invert、Saturate、Sepia、Pixelate、Noise。参数键完整对照见 样式配置项：滤镜参数。

阴影 ​

ts
shape.s({
  shadow: true,
  shadowColor: 'rgba(0,0,0,0.35)',

像素级命中（pixelPerfect） ​

ts
// 单个元素开启
shape.s('pixelPerfect', true);

// 或全局设置为默认（编辑器即如此配置）
defineConfig({ defaultStyles: { Shape: { pixelPerfect: true } } });

开启后，Shape / Text 的命中从 OBB 几何检测升级为逐像素 alpha 检测（命中成本更高）。内置动画 Image / 自带动画 / renderHTML 元素例外，仍按包围盒命中。

完整的样式键、默认值与取值枚举对照表见 API 参考：样式配置项。

滤镜 / 混合 / 阴影对性能的影响 ​

  • 滤镜与内阴影使用离屏画布按元素缓存。
  • 手绘模式会跳过渐变、立体描边和虚线（按设计如此）。
  • 视口裁剪边界会自动外扩（expandBoundsForRough / expandBoundsForShadow）。
