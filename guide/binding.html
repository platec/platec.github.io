图标绑定 ​

图标绑定（Symbol Binding）是矢量图标元素（Image）的核心能力：符号内的任意字段（样式 / 属性）可以声明为一个「绑定表达式」，运行时从宿主 Image 元素读取实际值。这样同一个图标可以被多次复用并呈现不同内容（文本、颜色、显隐、图片…），无需复制符号。

概念模型 ​

一个可绑定的图标包含两层声明：

符号 JSON（资源）
├── bind[]                         符号级「可绑定属性」清单（用户界面元数据）
│   ├── { attr: 'unit', valueType: 'String', name: '单位', defaultValue: 'kW' }
│   └── ...
└── elements[].styles / props      元素级绑定表达式（消费方）
    └── "text": { func: 'attr@unit', value: 'kW' }
  • bind[] —— 声明这个符号对外暴露哪些属性（attr 名、值类型、默认值、显示名）。valueType 只是编辑器渲染控件用的元数据，核心运行时不校验。
  • 元素级表达式 —— 符号内某个元素（Shape/Text/Polyline…）的某个字段标记为绑定样式：{ func, value }。绘制该字段时先对表达式求值，求值失败 / 无值则回退 value。

上方演示直接使用编辑器内置图标 symbols/circleProgressBar.json（编辑器资源面板「图标」页签中的环形进度条），依赖链：

图纸中的 Image（setImage('symbols/circleProgressBar.json')）
└── 符号 symbols/circleProgressBar.json
    │   声明 bind[]，内部 Component 元素把组件属性映射为 attr@ 表达式
    └── 组件 components/basic/circleProgressBar.json
        properties 默认值表 + func 渲染函数（按需自动加载，无需手动注册）
jsonc
// symbols/circleProgressBar.json（节选）
{
  "width": 100, "height": 100,
  "elements": [{
    "type": "Component",
    "component": "components/basic/circleProgressBar.json",
    "progressPercentage": { "func": "attr@progressPercentage", "value": 1 },
    "linearOuter":        { "func": "attr@linearOuter" },
    "progressLineCap":    { "func": "attr@progressLineCap" },
    "x": 50, "y": 50, "width": 100, "height": 100
  }],
  "bind": [
    { "attr": "progressPercentage", "valueType": "Percentage", "name": "进度百分比" },
    { "attr": "linearOuter", "valueType": "ColorArray", "name": "圆环渐变色" },
    { "attr": "linearInner", "valueType": "ColorArray", "name": "内圆渐变色" },
    { "attr": "fontScale", "valueType": "Number", "name": "字体缩放比例" },
    { "attr": "showOrigin", "valueType": "Boolean", "name": "是否显示为原始值" },
    { "attr": "progressLineCap", "valueType": "CapStyle", "name": "进度条样式" }
  ]
}

组件资源携带 properties 默认值表与渲染函数 func(g, rect, comp, data, view)，渲染时通过 comp.getValue('progressPercentage') 读取求值结果（求值次序见下文「组件属性」）：

jsonc
// components/basic/circleProgressBar.json（节选）
{
  "width": 100, "height": 100,
  "properties": {
    "progressPercentage": { "valueType": "Percentage", "defaultValue": 0.75 },
    "linearOuter": { "valueType": "ColorArray", "defaultValue": ["#26a67b", "#0474d6"] },
    "progressLineCap": { "valueType": "CapStyle", "defaultValue": "butt" }
  },
  "func": "function(g, rect, comp, data, view) { /* 用 comp.getValue(...) 绘制圆环与读数 */ }"
}

演示源码见 packages/docs/theme/demos/DemoBinding.vue；两个 JSON 资源已收录在 packages/docs/public/（与编辑器 packages/editor/public/ 中的版本一致），运行时按名称自动加载。

该符号的 bind[] 中还有一项 isAnimate（HT 遗留的「进度动画」开关）：核心运行时不消费它，Image / Component 均未引用。需要进度动画时用 Tween 逐帧写入 progressPercentage 即可（演示中的「▶ 播放进度动画」按钮就是这么做的）。

绑定表达式 ​

三种写法（字段类型：{ func: string | Function, value?: any }）：

表达式含义示例
attr@<name>读宿主 Image 的 attr"text": { "func": "attr@unit" }
prop@<name>读宿主元素 props（映射为 getXxx()）"image": { "func": "prop@image" }
函数接收宿主 Image 参数，返回实际值"borderColor": { "func": (host) => host.a('enabled') ? '#2a7f72' : '#bbb' }

求值链（draw/style.ts 的 getStyle）：

绑定表达式求值（attr@ / prop@ / 函数）
  → 求值结果 === undefined 时回退绑定默认值 value
  → 仍 undefined 时回退 defaultVectorStyles 类型默认

函数绑定抛异常时不中断绘制，回退到 value（并 console.warn）。

运行时更新 ​

ts
const img = new Image();
img.setImage('icon/仪表/温度计');

// 读取：未设置 attr 时自动回退符号 bind[] 的 defaultValue
img.a('unit');            // '℃'

// 写入：触发 a:unit 变更事件 → 视图重绘该元素
img.a('unit', '℉');

Image.getAttr 覆写了对 bind.defaultValue 的兜底（src/Image.ts:56）；setAttr 发出 a:<name> 事件，触发 View 重绘。

组件属性（Component） ​

组件（Component 元素 + 组件定义）同样支持绑定：

组件定义（components/*.json）
└── properties: { progressPercentage: { valueType: 'Number', defaultValue: 0.75, ... } }

符号内组件元素
└── "progressPercentage": { "func": "attr@progressPercentage", "value": 1 }

组件渲染时（draw/component.ts）按 attr@ → 绑定默认值 → 组件定义 defaultValue 的次序求值。组件内部通过 comp.getValue(name) / comp.getColor(name) 读取。

示例 ​

文本绑定 ​

jsonc
// 符号 JSON
{
  "bind": [{ "attr": "unit", "valueType": "String", "name": "单位", "defaultValue": "kW" }],
  "elements": [{
    "type": "Text",
    "styles": { "text": { "func": "attr@unit", "value": "kW" } }
  }]
}
ts
img.a('unit', 'kVA');   // 图标内文本随之更新

颜色绑定 ​

jsonc
{ "bind": [{ "attr": "lineColor", "valueType": "Color", "name": "线路颜色" }],
  "elements": [{
    "type": "Polyline",
    "styles": { "borderColor": { "func": "attr@lineColor", "value": "#2563eb" } }
  }] }

布尔显隐 ​

jsonc
"label": { "func": "attr@showUnit" },

→ 绑定值 false 时 getStyle 回退到 value 或类型默认（''），自然隐藏。

图片 / 组件绑定 ​

"image": { "func": "attr@img" }、"component": { "func": "attr@comp" } —— 编辑器中对 valueType: 'Image' 的绑定值控件可直接拖放资源。

函数绑定（图元状态） ​

jsonc
"borderColor": { "func": "host => host.a('enabled') ? '#2a7f72' : '#cbd5e1'" },
"fillOpacity":  { "func": "host => host.a('enabled') ? 1 : 0.4" }

ECharts 复合绑定 ​

图表/通用ECharts.json 把整个 option 暴露为一个 valueType: 'Json' 的绑定属性：

jsonc
{ "bind": [{ "attr": "option", "valueType": "Json", "name": "ECharts 配置",
             "defaultValue": { "title": { "text": "ECharts 通用配置" }, ... } }] }

编辑器中的配置 ​

图形编辑器（在线体验，源码 packages/editor）提供了完整的绑定配置 UI：

  1. 符号绑定清单 —— 图标的「绑定」页签编辑 bind[]：新增 / 删除绑定属性，设置 attr、值类型、默认值、显示名与描述。
  2. 样式关联 —— 选中符号内元素，对任意样式字段打开绑定对话框，选择「关联属性」（生成 attr@）、「函数」（生成函数表达式）或「固定值」。
  3. 绑定值控件 —— 属性面板的绑定值编辑器（BindingValueControl）按 valueType 渲染对应控件：
valueType控件legacy 兼容
Image / Font专用编辑器（图片支持拖放资源）—
String / Number / Boolean / Color / Angle文本框 / 数字 / 开关 / 取色器 / 角度表PositiveNumber / Percentage / CapStyle
GradientPack渐变编辑器—
Function函数代码编辑—
Object / ObjectArray / *ArrayJSON / 列表编辑器Json
  1. 运行时编辑 —— 图纸编辑页中，直接修改选中图标的绑定属性（属性面板「绑定」tab），即时生效并随图纸序列化。

数据流总结 ​

符号 XML/SVG ──(svg-to-symbol 导入，不解析绑定)──▶ 符号 JSON（bind: [] 为空）

编辑器绑定配置（符号绑定清单 + 样式关联对话框）
  └─▶ 符号 JSON.write bind[] + 元素级 { func, value }

图纸中使用：Image.setImage(符号) → a(name, value) 覆盖绑定值
  └─▶ Image.getAttr / a:name 事件 / draw 时 getStyle 求值
  └─▶ 触发 View 重绘（全画布重绘，非元素级局部重绘）

注意事项 ​

  • SVG 导入默认不生成绑定：svg-to-symbol.ts 输出空 bind，绑定由编辑器配置或手写 JSON 产生。
  • 绑定值是符号实例级：同一个图标放在不同位置，各自 attr 独立，互不影响。
  • 序列化时表达式保留：func（如 attr@unit）原样写入，value 刷新为当前实例值；符号内部属性（__symbol*）不会泄漏到导出的图纸 JSON。
  • 性能：a(name, value) 触发全画布重绘（ViewRenderer 无元素级局部重绘）；请避免高频逐帧写入（可使用 Tween 的 onUpdate 搭配 onFrame 之类的节流）。
  • 与 renderHTML / attachPoints 的区别：绑定驱动的是符号内容的样式；renderHTML 是 DOM 叠加层；attachPoints 是 Connector 吸附锚点，三者独立。
