核心概念 ​

Storage + View 双核架构 ​

Leaf Plus 围绕两个主类构建，职责完全分离：

类职责
Storage数据模型：持有所有 Element 实例，管理序列化 / 反序列化、图层、排序、撤销重做、批量事务，并发出变更事件。
View渲染器 + 交互控制器：管理 <div> 内的 <canvas>，处理视口变换（平移 / 缩放）、命中检测、鼠标 / 触摸 / 手势事件，通过 requestAnimationFrame 驱动渲染循环。
ts
const storage = new Storage();
const view = new View(storage); // View 获取 Storage 引用
view.mount(document.body);

View 构造时内部会创建：ViewRenderer（渲染管线）、InteractionManager（交互）、OperationController（拖拽 / 选择操作）、SceneSpatialIndex（空间索引）、HtmlOverlay（HTML 叠加层）、ElementEventBinder（声明式事件绑定）。

坐标系 ​

  • 世界坐标（World）：场景图使用的坐标，例如 shape.setPosition(60, 140)。
  • 屏幕坐标（Screen）：浏览器视口 CSS 像素坐标。
ts
const worldPoint = view.screenToWorld({ x: 100, y: 100 });
const screenPoint = view.worldToScreen(worldPoint);

交互事件中的 x / y 均为世界坐标。

视口变换 ​

ts
view.tx(100); view.ty(50);          // 平移视口（增量）
view.setScale(1.5);                 // 缩放（自动 clamp 到 min/max）
view.zoomToPoint(1.5, { x: 100, y: 100 });  // 以世界点为中心缩放
view.panTo(100, 100);               // 平移至世界坐标（居中）
view.fitContent(20, true);          // 适应全部内容（带 300ms 补间动画）

缩放范围默认 0.05 至 64，可通过 setScaleRange(min, max) 调整。

渲染循环 ​

  • 对 Storage 的 elementChange / storageChange 事件，View 会自动请求重绘。
  • storage.batch(fn) 将多次变更合并为一次渲染。
  • 资源加载完成后（resourceLoaded）也会触发重绘。
  • 主 Canvas 默认使用脏矩形重绘：只重绘内容变化的区域（配合空间索引收集候选元素），半透明图形按外扩安全边界重绘避免残留；可通过 view.setDirtyRectEnabled() 关闭，view.getRenderStats() 查看每帧策略（见 API 参考：View）。
ts
storage.batch(() => {
  shape.setPosition(100, 200);
  shape.setSize(200, 100);
  text.setSize(80, 40);
}); // 仅一次重绘

图层 ​

Storage 支持图层（Layer { name, visible, selectable, movable, editable }）：

ts
storage.setLayers([
  { name: '背景', visible: true },
  { name: '主图', visible: true, selectable: true, movable: true, editable: true },
]);

storage.add(shape);
storage.getElementsByLayer('背景').forEach((el) => {
  el.setLayer('主图');
});

ID 与 Tag ​

ts
shape.setId(42);
storage.getElementById(42);        // O(1) 查询
shape.setTag('start-node');        // 自定义标签
storage.getElementByTag('start-node');

节点关联：父子树与宿主吸附 ​

节点间有两种相互独立的关联方式：

机制API语义
父子树group.add(child)层级容器：子节点世界矩阵跟随父链（见 元素系统）
宿主吸附node.setHost(host)HT 风格吸附：跟随宿主平移 / 旋转，并按 layoutH / layoutV 约束随宿主尺寸变化重排（见 元素系统）

宿主吸附不改变渲染层级（非父子树），适合「背景 / 水印 / 边框跟随画布」这类布局诉求；fullscreen 样式则直接让节点铺满视口。

撤销 / 重做 ​

ts
storage.enableHistory(true, 100);  // 开启历史记录（上限 100 条）
storage.undo();
storage.redo();
storage.canUndo();
storage.canRedo();

历史事件通过 historyChange 通知 UI 更新按钮状态。交互操作（拖拽等）自动合并为单个历史记录。

事件总线 ​

  • Storage 发出：elementChange、storageChange、historyChange。
  • View 发出：viewportChange、selectionChange、clickElement、clickBackground 等。
  • 全局资源事件：resourceLoaded / resourceReleased。
ts
storage.on('storageChange', (arg) => {
  console.log('场景变更类型:', arg.type); // 'add' | 'remove' | ...
});

View 在销毁时会解除与 Storage 的绑定，请调用 view.destroy() 释放资源。
