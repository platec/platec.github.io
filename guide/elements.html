元素系统 ​

元素层级 ​

Element                      基类（样式系统、属性系统、父子树、变换缓存）
├── Node                     增加 2D 变换与包围盒几何
│   ├── Shape                图形图元（矩形/圆/星形/多边形等）
│   ├── Text                 文本图元
│   ├── Image                图像 / 矢量图标图元
│   ├── Polyline             折线 / 贝塞尔路径图元
│   └── Group                节点容器（组合）
└── Connector                连接线（连接两个 Node，本身不是 Node）

复合矢量符号（由 SVG/Stencil 转义得到）：

Component        矢量图标内的可编辑可替换组件
Clip / Restore   矢量图标裁剪范围起止标记

元素三大数据面 ​

每个元素的数据由三部分构成：

面API说明
PropssetPosition / setSize / setId 等结构化属性（位置、尺寸、变换、引用）。
Stylesel.s({ ... })样式键值（颜色、描边、渐变…），有默认值。
Attrsel.a('key', value)任意业务属性，不参与样式解析。
ts
shape.s('background', '#d8eee9');   // 设置单个样式
shape.s({ background: '#d8eee9' }); // 批量设置
shape.s('background');              // 读取

shape.a('name', '泵站 A');          // 属性（Image 会回退到矢量资源 bind 默认值）
shape.a('name');

样式解析顺序：实例样式 → 类型默认样式 → 全局默认样式 → 插件注册的默认值。

节点变换 ​

Node 支持平移、缩放、旋转、倾斜与锚点：

ts
const node = new Shape();
node.setPosition(60, 140);          // setX / setY 亦可用
node.setSize(120, 60);              // setWidth / setHeight / setSize
node.setScale(1.5, 1.5);            // 必须同时传 x、y；也支持 setScale({x, y})
node.setRotation(Math.PI / 4);
node.setSkewX(0.15);
node.setAnchor(0.5, 0.5);           // 变换锚点（相对自身宽高）

变换缓存使用版本号方案：调用 _invalidateTransform() 递增版本号，失效会递归传播到子元素。

命中检测 ​

ts
node.containsPoint(worldX, worldY);          // OBB 精确检测
node.getBoundingBox();                       // 计算包围盒（每次重新计算）
node.intersectsBoundingBox(other);           // 包围盒相交测试

命中流程：先对元素包围盒做 AABB 剔除（配合空间索引），再执行 Node.containsPoint 的 OBB 检测。开启 pixelPerfect 后会把候选元素绘制到离屏画布并检查 alpha 通道，实现像素级命中。

父子树 ​

ts
group.add(child);                    // 加入组
group.addChildren([a, b]);           // 批量
group.remove(child);
group.getChildren();
group.getChildById(id);
  • 子元素的世界矩阵依赖父链，父节点变换后子元素自动跟随（世界矩阵递归计算）。
  • Group 不会绘制自身，仅绘制子节点。
  • getConnectors() 返回连接到该元素的 Connector 列表。

宿主吸附（Host） ​

与 Group 层级独立的另一种节点关联方式：节点通过 setHost() 吸附到宿主，宿主平移 / 旋转时吸附节点跟随，宿主尺寸变化时按布局约束自动重排（HT 风格吸附语义）：

ts
const host = new Shape(); host.setSize(200, 100);
const child = new Shape(); child.setSize(20, 20);

child.setHost(host);                  // 吸附到宿主
child.s('layoutH', 'left');           // 水平：左侧固定
child.s('layoutV', 'topbottom');      // 垂直：上下固定并随宿主拉伸

host.setPosition(120, 110);           // child 同步平移
host.setSize(300, 200);               // child 保持左边距，高度随宿主拉伸
  • 宿主可以是任意 Node；一个宿主可挂多个吸附节点（host.getAttaches()）。
  • layoutH / layoutV 提供固定边距（left/right/center、top/bottom/center）、随宿主拉伸（leftright/topbottom）与等比缩放（scale）三类约束。
  • fullscreen 样式让节点直接铺满视口（fill 拉伸 / uniform 等比居中），常用于背景图、水印等固定层，编辑模式下不生效。
  • 宿主关系序列化为 props.host = { id }，随图纸 JSON 往返。
  • 完整 API 见 API 参考：Node 宿主吸附。

标签 ​

所有 Node / Connector 支持标签（通过 label* 样式族）：

ts
shape.s({
  label: '泵站 A',
  labelColor: '#0f3d3a',
  labelFont: '12px sans-serif',
  labelPosition: 17,       // 居中（HT 1–55 位置系统，见样式配置项）
  labelAlign: 'center',
});

交互属性 ​

ts
shape.setInteractive(true);          // 开启交互
shape.setEvents({
  // 字符串脚本由内置编译器编译执行；仅写函数体时自动获得 (event, element, view) 三个参数
  onClick: "element.s('background', '#f8d7da')",
  onEnter: "element.s('borderColor', '#e03131')",
  onLeave: "element.s('borderColor', '#2a7f72')",
  onEndDrag: "console.log('拖放到', element.getPosition())",
});

interactive / events 在序列化后会写入 props，由 View 内建的 ElementEventBinder 自动绑定，可用 view.setElementEventsEnabled(false) 全局关闭。

Image（矢量图标）支持「图标绑定」：符号内部字段声明绑定表达式，运行时从宿主 Image 的属性读取实际值，详见 图标绑定。
