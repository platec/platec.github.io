交互与事件 ​

交互类型 ​

View 提供两级事件处理：

级别API说明
元素级view.onElementEvent(element, type, handler)限定特定元素，支持沿父链冒泡。
全局级view.onInteraction(type, handler)可交互元素 / 画布空白上的交互会触发。

interactive 是交互事件的总开关：interactive === false（默认）的元素对交互事件透明—— onElementEvent 监听不会触发，作用在它上面的交互也不会触发全局 onInteraction， 事件沿父链继续冒泡到可交互的祖先。命中检测与选中 / 移动 / 控制点等编辑操作不读取该标志， 即一个图形可以"可选中、可移动，但不响应业务交互事件"。

完整的交互类型（InteractionEventType）：

  • 鼠标：mousedown、mousemove、mouseup、click、dblclick、mouseenter、mouseleave、mouseover、mouseout、hover、contextmenu、wheel
  • 触摸：touchstart、touchmove、touchend、touchcancel
  • 合成手势：pan、pinch、rotate、swipe、tap、longpress
  • 拖拽体系：dragstart、drag、dragend
  • 画布：clickBackground、clickElement

事件参数 ​

ts
view.onInteraction('click', (event) => {
  event.type; // 'click'
  event.originalEvent; // 原生事件（PointerEvent 等）
  event.target; // 命中的元素（可能为 null）
  event.x;
  event.y; // 世界坐标
  event.clientX;
  event.clientY; // 屏幕坐标
  event.deltaX / deltaY; // 拖拽 / 手势增量
  event.scale;
  event.rotation; // pinch / rotate 手势
  event.isTouch;
  event.buttons;
  event.ctrlKey / shiftKey / altKey / metaKey;
  event.stopPropagation();
  event.preventDefault();
});

元素级事件 ​

ts
shape.setInteractive(true); // 必需：interactive=false 时监听不会触发

// 方式一：通过 View 订阅
view.onElementEvent(shape, 'click', (event) => {
  console.log('Shape 点击', event.target);
});
view.offElementEvent(shape, 'click');

// 方式二：直接订阅元素自身 emitter，与方式一同等生效
shape.on('click', (event) => {
  /* ... */
});
shape.once('mouseenter', (event) => {
  /* 仅触发一次 */
});
  • 父链（Group → 根）上注册的事件也会触发，事件一路冒泡。
  • 冒泡路径上 interactive === false 的元素被跳过（自身监听不触发），但不阻断继续向上冒泡。
  • dblclick 需要先触发 click，注意两者语义。
  • 调用 event.stopPropagation() 可中断冒泡（处理器返回值不参与冒泡控制）。

全局交互 ​

ts
view.onInteraction('pan', (event) => {
  /* 拖动画布 */
});
view.onInteraction('dragend', (event) => {
  /* 元素拖拽结束 */
});
  • 点击空白（无命中元素）时照常触发。
  • 作用在 interactive === false 元素上的交互不触发；若其某个祖先可交互，则在祖先那一跳触发。

clickElement / clickBackground 不在 onInteraction 通道上，需通过 View 事件订阅（见下方「视口事件」表）：

ts
view.on('clickElement', (e) => {
  console.log('命中元素', e.data);
});
view.on('clickBackground', (e) => {
  console.log('点击空白');
});

视口事件 ​

View 自身的事件（view.on(...)）：

事件载荷说明
viewportChange{ tx, ty, scale }视口变换
selectionChange{ data: Element[] }选择集变化
clickElement{ kind: 'clickData', event, data }点击元素（页面级）
clickBackground{ kind: 'clickBackground', event }点击空白
wheel{ event }滚轮
contextmenu{ event }右键
canvasDragStart/canvasDrag/canvasDragEndViewDragEvent画布拖拽
elementDragStart/elementDrag/elementDragEndViewDragEvent元素拖拽
ts
view.on('selectionChange', ({ data }) => {
  console.log('选中:', data);
});

拖拽系统 ​

ts
view.onInteraction('dragstart', (event) => {
  console.log('开始拖拽元素:', event.data);
});
view.onInteraction('drag', (event) => {
  console.log('增量: Δ(%d, %d)', event.deltaX, event.deltaY);
});

view.isDragging(); // 元素拖拽中？
view.getDraggedData(); // 被拖拽的元素
view.isCanvasDragging(); // 画布平移中？

选择 ​

ts
view.setSelectedElement(element); // 单选
view.setSelectedElements([a, b]); // 多选
view.getSelectedElement();
view.getSelectedElements();
view.getMarqueeRect(); // 框选矩形（世界坐标）

选择状态变化会触发 selectionChange。editMode(true) 后点击默认为「选择」操作。

剪贴板（复制 / 粘贴） ​

ClipboardController 以 Storage 序列化数据为载体实现复制 / 粘贴，绑定单个 View。复制时取选中元素的顶层根、连同 Group 子树整体序列化，并过滤两端未一起复制的「悬空」Connector；粘贴时重新分配元素 ID、清除唯一 tag、重绑定 Connector 的 start / end 引用，并相对原位置按步长偏移。粘贴成功后剪贴板即被清空。

ts
import { ClipboardController } from '@leaf-plus/core';

const clipboard = new ClipboardController(view);

// 复制当前选中元素（也可显式传入 elements）
clipboard.copy();
clipboard.copy({ elements: [shapeA, shapeB] });

clipboard.isEmpty(); // 是否为空

// 粘贴：返回新建的克隆元素，可直接选中它们
const clones = clipboard.paste({ offset: 20 }); // offset 为偏移步长（默认 20）
view.setSelectedElements(clones);

跨 View（如编辑器多标签页）共享剪贴板：用 getData() / setData() 导出并注入同一份数据。

ts
const data = sourceClipboard.getData(); // 深拷贝快照
// ...切换到另一个 View...
targetClipboard.setData(data);
const clones = targetClipboard.paste();

编辑器即用此机制：view.copyToClipboard() / view.clipboard.getData() / view.pasteFromClipboard() 配合 Ctrl/Cmd+C、Ctrl/Cmd+V，由 core 完成 ID 重分配与连线重绑。

命中检测 ​

ts
const hit = view.getElementAt(event); // 命中一个元素
const hits = view.getElementsAtPoint(100, 100); // 全部命中（自上而下）
const hitsInRect = view.getElementsInRect({
  x: 0,
  y: 0,
  width: 100,
  height: 100,
});

命中流程：

  1. AABB 剔除 —— SceneSpatialIndex 空间索引快速定位候选。
  2. OBB 精确检测 —— Node.containsPoint 使用定向包围盒。
  3. 像素级检测（可选）—— pixelPerfect 样式开启后绘制到离屏画布检查 alpha。

容器命中策略：Group 默认自身整体参与命中（syncSize 默认 true 时命中不深入子节点）。 设置 element.setHitPassthrough(true) 可开启命中穿透：元素对点命中完全透明， 命中检测直接递归子元素，未命中子元素时视为未命中（自身不做兜底）。穿透是全链路的， 编辑模式下点选同样穿透到子元素，整组仍可通过框选或图形列表选中。该属性参与 JSON 序列化（props.hitPassthrough），与 interactive / selectable 正交： 穿透决定"命中到谁"，selectable 决定"能否选中"，interactive 决定"是否分发交互事件"。

声明式事件交互 ​

元素 props 中的 interactive / events 支持声明式绑定（代码为字符串，由内置编译器执行）：

ts
shape.setInteractive(true);
shape.setEvents({
  // 仅写函数体：自动获得 (event, element, view) 三个参数
  onClick: "element.s('background', '#ffe8cc')",
  onEnter: "element.s('opacity', 0.85)",
  onLeave: "element.s('opacity', 1)",
  // 也可写完整函数表达式
  onEndDrag:
    "function (event, element) { console.log('拖放到', element.getPosition()); }",
});

view.setElementEventsEnabled(false); // 全局开关

这类配置在 JSON 序列化后往返依旧生效，适合低代码 / 编辑器场景。

ts
import type { GestureConfig } from '@leaf-plus/core';

view.setGestureConfig({
  tapDelay: 300, // tap 判定等待（ms）

  swipeVelocityThreshold: 0.5,

编辑模式 ​

ts
view.editMode(true); // 开启编辑（拖拽、选择、吸附锚点编辑等）
view.editMode(false); // 只读预览

编辑模式关闭时点击不再改变选择集（仅预览），但可移动元素（movable）仍可被拖拽；已监听的事件照常发出。

视口交互开关 ​

非编辑模式下可通过 storage 属性锁定视口缩放 / 平移（编辑模式始终允许，不影响编辑操作）：

ts
const storage = view.getStorage();
storage.setAttr('zoomable', false); // 禁用滚轮 / 手势缩放
storage.setAttr('pannable', false); // 禁用拖拽 / 手势平移

view.isZoomable(); // 非编辑模式读取开关
view.isPannable();
  • 关闭后滚轮缩放、双指捏合、画布拖拽平移均不响应；元素选择 / 点击仍正常。
  • 配合 storage.setAttr('fitContent', true) 可在预览打开时自动适配内容（见 API 参考：View）。
  • 这些配置随图纸 JSON 往返，适合「只读展示型图纸」：打开即适配、不允许用户拖动画面。
