图形编辑器 ​

Leaf Plus Editor 是基于 @leaf-plus/core 构建的完整图形编辑器（Vue 3 + naive-ui），覆盖图纸 / 图标（矢量符号）/ 组件三类资源的编辑。它既是开箱即用的作图工具，也是核心库全部能力的最佳实践参考。

在线体验

👉 https://platec.github.io/editor/ —— 纯静态部署，打开即用，无需安装。

功能概览 ​

模块能力
资源管理图纸 / 图标 / 资源 / 组件四个页签；新建、重命名、删除、树形分组；支持导入 Mermaid、DXF、SVG、drawio 文件生成图纸
绘制工具选择、矩形、圆角矩形、圆形、三角形、文本、折线、画笔（自由线条）、连接线、动画
属性面板属性 / 样式 / 绑定三个页签：位置尺寸、旋转锚点、全部样式键、图层归属、标签位置选择器等；滤镜编辑器支持多滤镜链与参数化编辑（35 种内置效果，旧版滤镜自动提示迁移）；动画编辑器基于效果元信息生成参数表单，并支持 $play / $speed 及动画参数的属性绑定；折线 / 连接线支持控制点模式编辑（line / mirror / disconnected / asymmetric）；样式页签含「布局」组：宿主图元（可从图形列表拖入）、全屏适配、水平 / 垂直布局约束
图标编辑矢量符号的绑定清单（bind[]）配置、样式关联绑定对话框、吸附锚点（AttachPoint）编辑、组件槽位配置（见 图标绑定）。组件只能拖入图标画布，组件定义在内存草稿中编辑、保存即刷新全部画布缓存
画布交互框选 / 多选、拖拽移动、8 手柄缩放、旋转、控制点编辑、右键菜单（触屏长按唤起）、资源触屏拖拽入画布、元素列表；复制 / 粘贴保留旋转缩放、重映射 id 并重写连接线引用；图纸属性可配置「运行交互」（适配内容 / 可缩放 / 可平移）
历史记录撤销（Ctrl+Z）/ 重做（Ctrl+Y），交互操作自动合并为单条历史
导出导出 PNG 图片、导出 SVG（可编辑矢量，图标导出为透明背景）、导出 JSON（storage.serialize()）
预览以非编辑模式打开图纸 / 图标，实时查看动画与交互效果

图形库（Stencils） ​

编辑器内置 mxGraph / drawio 图形库（AWS、Azure、BPMN、Cisco、阿里云等数十个类目），按需懒加载本地 XML 库文件。拖入画布的形状即核心库的 Shape（shape: 'stencil:<name>' 或 'mxgraph.*'），绘制与序列化均由核心库完成。

布局与运行交互配置 ​

样式页签的「布局」组暴露核心库的宿主吸附与全屏适配能力（见 元素系统：宿主吸附）：

配置项对应核心库说明
宿主图元node.setHost(host)从元素列表拖入图形即吸附为该节点的宿主；宿主移动 / 缩放时节点跟随
全屏适配样式 fullscreenfill 拉伸填满视口 / uniform 等比完整显示，编辑模式下不生效
水平布局样式 layoutH左 / 右 / 水平居中 / 左右拉伸 / 等比缩放
垂直布局样式 layoutV上 / 下 / 垂直居中 / 上下拉伸 / 等比缩放

图纸属性面板的「运行交互」组配置预览模式下的视口行为，写入图纸顶层 attrs（见 序列化：运行配置 attrs）：

配置项对应 storage attr说明
适配内容fitContent预览打开时自动 fitContent，图纸内容居中适配
可缩放zoomable非编辑模式锁定 / 允许滚轮与手势缩放
可平移pannable非编辑模式锁定 / 允许拖拽平移

与核心库的关系 ​

编辑器的每一步操作都是对核心库 API 的直接调用，可以把它当作「会说话的示例代码」：

编辑器动作核心库 API
拖入图形 / 绘制图元new Shape() → storage.add(shape)
修改样式面板element.s({ ... })
修改绑定值image.a(name, value)
保存图纸storage.recalculateContentRect() → storage.serialize()
打开图纸storage.deserialize(json) → view.fitContent()
撤销 / 重做storage.undo() / storage.redo()
滤镜链编辑node.filterEffects([...])（FilterDescriptor 多滤镜链）
动画参数编辑element.setAnimations([...]) + getAnimationEffectMetas()
控制点模式编辑polyline.setControlPointMode(i, mode) / Connector 同组 API
预览新建 View（只读模式）渲染同一份 JSON

动画参数表单通过 getAnimationEffect(type)?.meta 读取当前动画效果的参数元信息渲染；滤镜编辑器基于核心库的 filterEffects（FilterDescriptor）体系，覆盖全部 35 种内置效果类型，并能把旧图纸的滤镜类配置迁移为滤镜效果；绑定值控件按 valueType 分发。

本地运行 ​

编辑器是 pnpm workspace 的 packages/editor 包：

bash
# 安装依赖（仓库根目录）
pnpm install

# 开发服务器
pnpm dev:editor

# 构建
pnpm --dir packages/editor build

# 单元测试（vitest + jsdom）
pnpm --dir packages/editor test

源码结构：

packages/editor/src
├── App.vue                  # 主逻辑（工具、图纸管理、属性应用）
├── components/              # 工具栏 / 资源面板 / 属性面板 / 各编辑器对话框
├── config/                  # 绑定类型、属性表单、stencil 类目清单（脚本生成）
└── utils/                   # svg-to-symbol、drawio/dxf/mermaid 转换等

注意

public/assets/stencils/ 下新增 stencil XML 库后，需重新生成类目清单：

bash
node packages/editor/scripts/generate-stencil-manifest.mjs
