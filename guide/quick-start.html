快速开始 ​

安装 ​

bash
pnpm add @leaf-plus/core
bash
npm install @leaf-plus/core
bash
yarn add @leaf-plus/core

核心库无运行时依赖（源码零第三方 import，package.json 不声明 dependencies）。

引入 ​

@leaf-plus/core 的默认入口直接指向 TypeScript 源码，开发时天然支持 tree-shaking（构建工具会自动编译）。如果想使用预构建产物（无需源码编译）：

子路径说明
@leaf-plus/core/esm预构建 ESM（未压缩）
@leaf-plus/core/esm.min预构建 ESM（压缩）
@leaf-plus/core/umdUMD 格式（CommonJS / 浏览器全局）
@leaf-plus/core/umd.minUMD 压缩版
@leaf-plus/core/dist按环境自动选择
ts
import { Storage, View, Shape } from '@leaf-plus/core';
ts
import { Storage, View, Shape } from '@leaf-plus/core/esm';
html
<script src="node_modules/@leaf-plus/core/dist/leaf-plus.umd.min.js"></script>
<script>
  const { Storage, View, Shape } = window.lp;
</script>

最小示例 ​

创建一个 View 并渲染一个矩形图元：

ts
import { Storage, View, Shape } from '@leaf-plus/core';

// 1. 数据模型
const storage = new Storage();

// 2. 渲染器与交互控制器
const view = new View(storage);
view.mount(document.getElementById('app')!);

// 3. 创建图元
const shape = new Shape();
shape.setPosition(60, 140);
shape.setSize(120, 60);
shape.s({
  shape: 'rect',
  background: '#d8eee9',
  borderColor: '#2a7f72',
  borderWidth: 2,
  label: 'A',
  labelColor: '#0f3d3a',
  labelFont: '12px sans-serif',
});

// 4. 加入场景
storage.add(shape);

// 5. 视图适配内容
view.fitContent();

效果：画布居中显示一个带描边与文字的矩形，支持滚轮缩放、拖拽平移。

交互示例 ​

ts
// 全局交互事件（作用于可交互元素与画布空白）
view.onInteraction('click', (event) => {
  console.log('点击坐标（世界坐标）:', event.x, event.y);
});

// 元素级事件（限定单个图元，支持沿父链冒泡）
// 注意：元素需先 setInteractive(true)，否则自身监听与全局
// onInteraction 都不会因其触发（选中/移动等编辑操作不受影响）
shape.setInteractive(true);
view.onElementEvent(shape, 'click', () => {
  console.log('Shape 被点击');
});

// 编辑模式：开启拖拽 / 选择等操作
view.editMode(true);

事件订阅 ​

ts
storage.on('elementChange', (arg) => {
  console.log('元素属性变化:', arg.property, arg.data);
});

view.on('viewportChange', ({ tx, ty, scale }) => {
  console.log('视口发生变换');
});

本地开发 ​

克隆仓库并运行文档 / 示例前，需构建核心库：

bash
# 安装依赖（pnpm workspace）
pnpm install

# 构建核心库
pnpm --filter @leaf-plus/core build

# 运行编辑器（完整的功能演示）
pnpm dev:editor

# 运行文档站
pnpm dev:docs

也可以直接访问在线编辑器 leafplus.me 体验全部功能，详见 图形编辑器。

TypeScript ​

核心库类型定义在 dist/leaf-plus.d.ts 中，提供完整的类型提示：

  • ElementStyles —— 全局样式接口，插件可通过 声明合并 扩展自定义样式键。
  • 所有事件（StorageEventMap、ViewEventMap、ElementEventMap）均为类型安全的事件映射。
ts
interface ElementStyles {
  text: string;
  background: string;
  // ... 数十个内置样式键
}
