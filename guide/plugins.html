插件系统 ​

插件是 Leaf Plus 的扩展机制：通过 usePlugin(plugin) 安装，unusePlugin(name) 卸载。插件注册的所有内容（样式默认值、绘制装饰器、动画效果）会在卸载时自动回滚。

安装 / 卸载 ​

ts
import { usePlugin, unusePlugin } from '@leaf-plus/core';

const uninstall = usePlugin(myPlugin);
unusePlugin('my-plugin'); // 通过名字卸载

已重名的插件再次安装会先卸载旧实例。

LeafPlugin 接口 ​

ts
import type { LeafPlugin, PluginContext } from '@leaf-plus/core';

const myPlugin: LeafPlugin = {
  name: 'my-plugin',
  version: '1.0.0',
  install(context: PluginContext) {
    // 注册能力...
  },
  uninstall() {
    // 可选清理（context 注册的内容会在卸载时自动回滚）
  },
};

PluginContext 能力 ​

API能力
registerStyleProperty(definition)扩展样式属性 + 默认值（{ key, defaultValue }）
registerDrawDecorator(decorator)在元素绘制前后插入自定义绘制
registerAnimationEffect(meta, effect)注册随插件卸载的动画效果
requestFrame(view)驱动持续动画（逐帧重绘）

1. 扩展样式属性 ​

ts
install(context) {
  context.registerStyleProperty({ key: 'myGlow', defaultValue: false });
}

自定义样式键的默认值会参与 Element.getStyle 的解析链；类型安全通过 TS 声明合并实现：

ts
declare global {
  interface ElementStyles {
    myGlow?: boolean;
    myGlowColor?: string;
  }
}

2. 绘制装饰器 ​

ts
context.registerDrawDecorator({
  name: 'my-glow',
  appliesTo: (element) => !!element.s('myGlow'), // 只对指定元素生效
  afterDraw: ({ ctx, element, view }) => {
    const box = element.getBoundingBox();
    ctx.save();
    ctx.globalAlpha = 0.3;
    ctx.fillStyle = element.s('myGlowColor');
    ctx.fillRect(box.x, box.y, box.width, box.height);
    ctx.restore();
  },
});
  • ctx 与元素位于同一坐标系（世界变换已应用）。
  • 交互缓存帧（pixelPerfect 命中用的离屏帧）不执行装饰器。
  • 装饰器按注册顺序执行。

3. 动画效果 ​

ts
import type { AnimationEffect } from '@leaf-plus/core';

const marquee: AnimationEffect = {
  update({ ctx, element, rect, elapsed, params }) {
    // 每帧在 Image/元素矩形内绘制（update/beforeDraw/afterDraw 三阶段）
  },
};

context.registerAnimationEffect(
  {
    type: 'marquee',
    label: '流动字幕',
    parameters: [
      { key: 'color', label: '颜色', type: 'color', defaultValue: '#ff0' },
    ],
  },
  marquee,
);

动画效果可通过 element.setAnimations([{ type: 'marquee', params: { color: '#f00' } }]) 应用。

4. 逐帧驱动 ​

ts
context.requestFrame(view); // 委托 View 持续 requestAnimationFrame

内置插件：leaf-flow（流动线） ​

流动线插件为 Polyline / Connector 扩展 flow 前缀的扁平样式键族，沿路径绘制流动的点阵拖尾：

ts
import { usePlugin, createFlowPlugin, Polyline } from '@leaf-plus/core';

usePlugin(createFlowPlugin()); // 安装（全局一次）

const line = new Polyline();
line.setPoints([
  { x: 0, y: 0 },
  { x: 100, y: 0 },
  { x: 100, y: 80 },
]);
line.s({
  borderWidth: 4,
  borderColor: '#2563eb',
  flow: true,
  flowStep: 1.5, // 流动速度（按 60fps 折算）
  flowCount: 2, // 流动组数量
  flowReverse: false,
  flowElementMax: 6,
  flowElementBackground: 'rgba(255,255,114,0.4)',
});
storage.add(line);

常用样式键（默认值）：flow(false)、flowReverse(false)、flowAutoReverse(false)、flowCount(1)、flowStep(1.5)、flowRenderMode('droplet')、flowElementCount(32)、flowElementBackground('rgba(255,255,114,0.4)')、flowElementMax(7)、flowElementMin(0.45)、flowElementSpace(0)、flowShadowVisible(true)。图片资源模式使用 flowRenderMode('icon')，并通过 flowElementImage、flowIconCount、flowIconWidth、flowIconHeight、flowIconRotate 配置。

实现原理：插件注册一个 afterDraw 装饰器（appliesTo: e => e.s('flow') === true），基于 PathWalker 弧长采样计算点阵，绘制后调用 requestFrame(view) 持续驱动。

内置插件：leaf-dashflow（虚线流动） ​

虚线本身由 core 原生的 dash 系列样式绘制，leaf-dashflow 只在每帧绘制前把 dashOffset 偏移一个随时间递增的量，绘制后还原，从而让虚线沿路径流动（常用于「蚂蚁线」选框、管道流向）。适用于 Shape / Polyline / Connector。

ts
import { usePlugin, createDashFlowPlugin, Polyline } from '@leaf-plus/core';

usePlugin(createDashFlowPlugin());

const pipe = new Polyline();
pipe.setPoints([
  { x: 0, y: 0 },
  { x: 160, y: 0 },
  { x: 160, y: 80 },
]);
pipe.s({
  borderWidth: 0, // 只保留虚线层
  dash: true, // core 原生虚线
  dashColor: '#2563eb',
  dashWidth: 3,
  dashPattern: [14, 10],
  dashFlow: true, // 开启流动
  dashFlowStep: 3, // 流动速度（px/帧，按 60fps 折算）
  dashFlowReverse: false, // 反向
});
storage.add(pipe);

样式键（默认值）：dashFlow(false)、dashFlowStep(3)、dashFlowReverse(false)。虚线不可见（未开 dash、dashWidth<=0 或 dashColor: 'transparent'）时插件不驱动动画。

内置插件：leaf-elastic（弹力连线） ​

为手动开启 elasticLine 的 Connector 绘制随两端距离拉伸而形变的正弦波形（弹簧线），常与力导向布局 / 物理模拟搭配。

ts
import {
  usePlugin,
  createElasticPlugin,
  resetElasticRestLength,
} from '@leaf-plus/core';

usePlugin(createElasticPlugin());

connector.s({
  elasticLine: true,
  elasticAmplitude: 10, // 波幅
  elasticWavelength: 28, // 波长
  elasticRestLength: 0, // 自然长度（0 = 首帧自动记录当前长度）
  elasticStretchGain: 1, // 拉伸增益：越拉波幅越大
});

resetElasticRestLength(connector); // 重置自然长度基准

渲染模式 ElasticRenderMode：'overlay'（默认，波形叠加在直线上）/ 'underlay' / 'replace'（用波形替换直线）。

内置插件：leaf-layout（自动布局） ​

安装后在 View 上扩展 view.layout(options)，对 Storage 中「节点 + 连接线」图做自动排布。布局算法只改节点位置并吸附连线端点，连接关系不变。

ts
import { usePlugin, createLayoutPlugin } from '@leaf-plus/core';

usePlugin(createLayoutPlugin());

view.layout({ type: 'mindmap', direction: 'H', hGap: 90, vGap: 26 });
view.layout({ type: 'tree', direction: 'TB', hGap: 40, vGap: 60 });
view.layout({ type: 'circular', mode: 'star', radius: 180 });
view.layout({ type: 'force', linkDistance: 160, chargeStrength: 3000 });
view.layout({ type: 'layered', direction: 'TB', hGap: 40, vGap: 60 });
布局 type说明关键参数
mindmap思维导图direction（H/LR/RL/TB/BT）、hGap、vGap、rootId
tree层级树direction（LR/RL/TB/BT）、hGap、vGap、rootId
circular环形mode（star 中心节点居中 / ring 等分成环）、radius、startAngle、clockwise
force力导向linkDistance、chargeStrength、iterations；可选写入 fast2d 物理样式
layered分层 DAG / 流程图direction、hGap、vGap

所有布局默认 snapAnchors: true（自动把连线端点吸附到节点朝向对方的边），设为 false 保留连线原有锚点。force 布局默认写入 fast2d 物理样式（physics / 距离关节），在运行态 View（如图纸预览）attach 物理插件后即呈现可拖拽、带回弹的弹性交互（见 Fast2D 物理插件）。

内置插件：动图与媒体（lottie / video / webp） ​

这三个插件让 Image 图元承载动态媒体。它们依赖浏览器能力或可选依赖，通常在应用启动时安装一次，用配套的图标工厂创建元素。

Lottie（.lottie / .json 动画）依赖可选依赖 @lottiefiles/dotlottie-web，需显式注入播放器构造器：

ts
import {
  usePlugin,
  createLottiePlugin,
  createLottieIcon,
} from '@leaf-plus/core';
import { DotLottie, DotLottieWorker } from '@lottiefiles/dotlottie-web';

usePlugin(createLottiePlugin({ DotLottie, DotLottieWorker }));

const icon = createLottieIcon({
  src: '/anim/loading.lottie',
  width: 120,
  height: 120,
});
storage.add(icon);

支持 Worker + OffscreenCanvas / Canvas2D / WebGL2 / WebGPU 多后端，环境不支持时按 worker → webgl → canvas 自动回退。

Video（mp4 / webm，浏览器原生解码逐帧贴回画布）：

ts
import { usePlugin, createVideoPlugin, createVideoIcon } from '@leaf-plus/core';

usePlugin(createVideoPlugin());

const video = createVideoIcon({
  src: '/media/clip.mp4',
  width: 320,
  height: 180,
  loop: true,
  muted: true,
});
storage.add(video);

动态 WebP / GIF（createWebpPlugin + createWebpIcon / createGifIcon，依赖 ImageDecoder）：

ts
import {
  usePlugin,
  createWebpPlugin,
  createWebpIcon,
  createGifIcon,
} from '@leaf-plus/core';

usePlugin(createWebpPlugin());

storage.add(
  createWebpIcon({ src: '/media/loading.webp', width: 96, height: 96 }),
);
storage.add(
  createGifIcon({ src: '/media/spinner.gif', width: 96, height: 96 }),
);

这三个插件需要真实媒体资源与浏览器解码能力，文档站未内嵌在线示例；实际效果参见图形编辑器（已内置注册，见 图形编辑器）与 packages/core/examples/ 下的 video-plugin.html、webp-filter.html。
