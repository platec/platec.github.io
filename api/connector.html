Connector ​

连接线。在两个 Node 之间绘制连接路径。Connector 本身不是 Node，不参与父子树与 OBB 检测；它直接在世界空间绘制。

ts
const connector = new Connector();
connector.setStart(nodeA);   // 自动在节点上注册/解绑引用
connector.setEnd(nodeB);
connector.s({
  borderColor: '#2563eb',
  borderWidth: 2,
  edgeStyle: 'orthogonal',
});
storage.add(connector);

端点 ​

方法说明
setStart(node) / getStart()起点节点（自动注册）
setEnd(node) / getEnd()终点节点
setStartPoint(point) / getStartPoint()在世界坐标移动端点（保持节点关联，自动换算为节点上的 anchor 比例）
setEndPoint(point) / getEndPoint()在世界坐标移动端点
ts
const startPoint = connector.getStartPoint();   // 世界坐标
const end = connector.getEndPoint();

setStart/setEnd 会自动在节点上注册连接器（node.getConnectors() 可查询）；节点销毁时自动解绑，序列化时以 { id } 引用写入 props。

连接样式 ​

edgeStyle 四种路径规约 ​

值效果
straight直线（默认）
orthogonal正交折线
elbow肘形折线
entityRelation实体关系（带引出段）
ts
connector.s('edgeStyle', 'orthogonal');
connector.s('elbow', 'vertical');       // 肘形方向偏好（'vertical' / 'horizontal'）
connector.s('jettySize', 10);           // 正交出线距离（默认 10；'auto' 时 20）
connector.s('sourceJettySize', 8);
connector.s('targetJettySize', 8);
connector.s('segment', 30);             // 实体关系引出长度（默认 30）

锚点 ​

ts
connector.s('startAnchorX', 0.5);  // 相对节点宽高
connector.s('startAnchorY', 0.5);
connector.s('endAnchorX', 0.5);
connector.s('endAnchorY', 0.5);
connector.s('startOffsetX', 0);
connector.s('startOffsetY', 0);

吸附点（attachPoint）模式：若端点节点是矢量图标并声明了 AttachPoint，Connector 会优先使用该吸附点。

端点标记 ​

ts
connector.s({
  startMarker: 'arrow',          // none | arrow | openArrow | diamond | circle | square | cross
  startMarkerSize: 12,
  // startMarkerWidth / startMarkerHeight / startMarkerColor / startMarkerStrokeColor
  // startMarkerStrokeWidth / startMarkerOffset / startMarkerRotation
  endMarker: 'diamond',
  endMarkerSize: 12,
});

自定义标记类型：registerMarkerType(name, factory)（见 工具函数）。

描边与虚线 ​

ts
connector.s({
  borderColor: '#2C3E50',
  borderWidth: 2,
  borderCap: 'round',
  borderJoin: 'round',
  dash: [6, 4],
  dashOffset: 0,
  dashColor: '#f59e0b',
  dashWidth: 2,
});

手工路径覆盖 ​

Connector 的路径默认由两个端点节点 + edgeStyle 计算。需要完全手工路径时使用样式键覆盖：

ts
connector.s({
  points: [{ x: 50, y: 50 }, { x: 150, y: 50 }, { x: 150, y: 120 }],
  segments: [1, 2, 3],   // 1=moveTo 2=lineTo 3=quadTo 4=bezier 5=closePath
});
connector.s('points', []);      // 清空覆盖，恢复 edgeStyle 自动路线

当 edgeStyle 切到非 straight 时，segments 覆盖会被自动清空；points 仍保留并作为路由经过点参与计算。

路径编辑 ​

方法说明
getPathPoints()世界坐标路径点（含端点）
getControlPoints()可编辑控制点
setControlPoint(i, p)更新控制点
insertControlPoint(index, point)在指定索引插入控制点（返回插入位置索引）
insertPointOnSegment(segIdx, t)在段内插点
removeControlPoint(i)删除控制点
setControlPointMode(i, mode)手柄模式（mirror/disconnected/asymmetric 等）
getControlPointMode(i) / getPathPointControlMode(i)查询手柄模式
toggleControlPointCurve(i) / togglePathPointCurve(i)切换该点曲线插值
getPathGeometry()得到路径几何（供采样）
tracePath()遍历路径
getLength()弧长
getPointAt(t)比例取样（0–1）

渲染与命中 ​

方法说明
getRenderTransform()返回 null（直接世界空间绘制）
getSelectionMode()返回 'path'
containsPoint(x, y, ctx)路径本身命中（Canvas isPointInStroke 描边级精确命中，最小 6px 命中宽度）
hitTest(point, ctx)命中检测（供 pixelPerfect 上下文）
getLocalRenderTransform()返回 null（Connector 无局部渲染变换，直接世界空间绘制）

标签与样式键 ​

Connector 与 Polyline 相同支持 label* 样式族与流动线插件（flow 前缀的扁平样式键）。完整样式键见 src/constants.ts 的 CONNECTOR_STYLE_KEYS。
