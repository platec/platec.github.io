View ​

Canvas 2D 渲染器与交互控制器。管理 <div> 内的 <canvas>，处理视口变换、命中检测、鼠标 / 触摸 / 手势事件，并以 requestAnimationFrame 驱动渲染循环。

ts
const view = new View(storage);   // 不传则内部 new Storage()
view.mount(document.getElementById('app')!);

生命周期 ​

方法说明
mount(parent?)挂载到 DOM（parent 缺省为 document.body）
destroy()销毁（解除事件与 ResizeObserver 资源）
getCanvas()主画布
getContext()主画布 2D 上下文
getView()容器元素（_view）
getStorage()绑定的 Storage
addChild(el)把 DOM 元素叠加进容器

旧示例中的 view._view 可直接 append；新代码推荐 view.mount()。

尺寸与像素比 ​

ts
view.setSize(800, 600);   // setWidth / setHeight
view.setPixelRatio(2);    // devicePixelRatio（默认取 window.devicePixelRatio）
view.getPixelRatio();
view.autoResize();        // 重新同步容器尺寸（构造函数内部由 ResizeObserver 驱动）
view.getWidth(); view.getHeight();

重绘诊断 ​

view.getRenderStats() 返回最近一个渲染帧的策略与开销，包括 strategy、reason、frameDurationMs、planningDurationMs、 drawDurationMs、candidateCount、dirtyRectCount、dirtyAreaRatio、 边界缓存命中 / 未命中次数，以及是否使用空间索引和交互位图缓存。尚未完成首帧时返回 null。

脏矩形重绘 ​

主 Canvas 默认开启脏矩形重绘：仅重绘内容变化的区域，并借助空间索引收集候选元素，避免每帧全量绘制。

ts
view.setDirtyRectEnabled(false);   // 关闭（切换时自动强制一次全量重绘重建基线）
view.isDirtyRectEnabled();         // 默认 true

view.setDirtyRectDebugEnabled(true);  // 在 overlay Canvas 上以半透明红色显示最近局部重绘区域
view.isDirtyRectDebugEnabled();
  • 关闭脏矩形后，每个内容帧都使用全量重绘。
  • 调试标记绘制在独立 overlay Canvas 上，开启 / 关闭不会触发主画布失效。
  • 半透明图形（阴影、渐变、低透明度元素等）在移动或动画时会按外扩的安全边界重绘，避免像素残留。

视口变换 ​

方法说明
tx(x?) / ty(y?)平移（get/set，缺省返回当前值）
scale(s?)缩放（set 时 clamp 到 min/max）
setScale(s) / getScale()同上显式形式
setScaleRange(min, max)缩放范围（默认 0.05 – 64）
getMatrix() / getTransform()当前变换矩阵
getViewportBounds()视口在世界坐标系中的范围
getBackgroundBounds()背景范围
fitContent(padding=20, animate=false)适应全部内容（带约 300ms 补间）
fitElement(element, padding=20, animate=false)适应单个元素
zoomToPoint(scale, worldPoint, animate=false)以世界点为锚缩放
panTo(x, y, animate=false)平移到世界坐标
editMode(value?)编辑 / 只读模式切换（get/set）
ts
view.fitContent(20, true);          // 动画适配
view.setScale(1.5);
view.tx(50); view.ty(20);           // 平移视口
view.scale(1.5);                    // scale(s) 与 setScale 等价

平移采用 tx(x) / ty(y)（set 时传参、get 时省略），亦可直接用 scale/tx/ty 读写。视口变换后自动重绘并触发 viewportChange。

视口交互开关 ​

非编辑模式下可通过 storage 属性控制用户能否缩放 / 平移视口；编辑模式始终允许（便于编辑操作）：

ts
view.isZoomable();    // 非编辑模式：storage.getAttr('zoomable') !== false
view.isPannable();    // 非编辑模式：storage.getAttr('pannable') !== false

view.getStorage().setAttr('zoomable', false);   // 预览模式禁用滚轮 / 手势缩放
view.getStorage().setAttr('pannable', false);   // 预览模式禁用拖拽平移

禁用后，滚轮缩放、双指捏合缩放、拖拽 / 手势平移均不生效（OperationController 按开关跳过）。

自动适配内容（fitContent） ​

设置 storage.setAttr('fitContent', true) 后，View 在非编辑模式下（挂载、尺寸变化、deserialize、attr:fitContent 变更等时机）自动执行一次 fitContent(20)，使图纸内容完整适配视口：

ts
view.getStorage().setAttr('fitContent', true);  // 只读预览时自动居中适配
  • 存在 fullscreen 节点时跳过自动适配（全屏适配由渲染管线直接处理，避免 fitContent 改变其展示基准）。
  • 该属性随 storage.serialize() 写入 attrs，随图纸 JSON 往返。

坐标转换 ​

ts
view.screenToWorld({ x: 100, y: 100 });   // 屏幕 CSS 像素 → 世界坐标
view.worldToScreen({ x: 0, y: 0 });

导出 PNG / SVG ​

ts
const blob = await view.toPNG({
  bounds: { x, y, width, height },  // 世界坐标；缺省优先取背景 bounds，其次内容包围盒
  width: 1920, height: 1440,        // 输出尺寸
  quality: 1,
});

// SVG：返回可编辑的矢量文档字符串
const svg = view.toSVG({
  bounds: { x, y, width, height },  // 世界坐标；缺省同上
  background: '#fff',               // 背景色；缺省取 Storage 背景，null 透明
});

详见 导出与独立绘制。

视图事件 ​

ts
view.on('viewportChange', (e) => console.log(e.tx, e.ty, e.scale));
view.on('selectionChange', (e) => console.log(e.data));
view.on('clickElement', (e) => {});
view.on('clickBackground', (e) => {});
view.once('wheel', (e) => {});
view.off('viewportChange', handler);
事件载荷
viewportChange{ tx, ty, scale }
selectionChange{ data: Element[] }
clickElement{ kind:'clickData', event, data }
clickBackground{ kind:'clickBackground', event }
wheel / contextmenu{ event }
canvasDragStart / canvasDrag / canvasDragEndViewDragEvent
elementDragStart / elementDrag / elementDragEndViewDragEvent

兼容旧 API：addEventListener / removeEventListener（deprecated，建议 on/off/once）。

交互事件代理 ​

ts
// 全局交互
view.onInteraction('click', (e) => {});
view.onInteraction('pan', (e) => {});
view.offInteraction('click', handler);
view.onceInteraction('dragend', handler);

// 元素级（沿父链冒泡）
view.onElementEvent(shape, 'click', (e) => {});
view.offElementEvent(shape, 'click');
view.onceElementEvent(shape, 'mouseenter', handler);

// 手势配置
view.setGestureConfig({ longPressDelay: 600 });
view.getGestureConfig();

// 声明式事件开关（interactive / events props）
view.setElementEventsEnabled(false);
view.isElementEventsEnabled();

命中检测 ​

ts
view.getElementAt(event);                        // 命中一个元素
view.getElementsAtPoint(worldX, worldY);         // 全部命中（自上而下）
view.getElementsInRect({ x, y, width, height }); // 矩形内

view.setSelectedElement(el | null);

拖拽状态 ​

ts
view.isDragging();           // 元素拖拽中？

view.isCanvasDragging();     // 画布平移中？

渲染控制 ​

方法说明
redraw() / _redraw()立即重绘
syncCache()刷新静态缓存（label / 矢量位图等）
clearCacheImages()清除图片缓存
getCacheImage(key) / setCacheImage(key, img)手动缓存条目
setCacheImageLimit(n)缓存上限
clearWorldCanvas(ctx?)清空世界画布
clearWorldRect(x, y, w, h, ctx?)清指定区域
setWheelPreventDefault(bool)阻止滚轮默认行为（页面滚动 vs 画布缩放）
setViewportCulling(bool)视口剔除开关
