Node ​

带 2D 变换和包围盒几何的节点基类。Shape / Text / Image / Polyline / Group 均继承自 Node。

ts
abstract class Node extends Element { /* 通过具体图元类实例化 */ }

方法说明
getPosition() / setPosition(x, y)位置（世界本体）
getX() / setX(x)、getY() / setY(y)分量形式

getAnchor() / setAnchor(x, y)变换锚点（相对自身宽高，默认 0.5, 0.5）
getAnchorX() / setAnchorX(x)、getAnchorY() / setAnchorY(y)锚点分量

node.setRotation(Math.PI / 6);

变换快照与编辑操作 ​

ts
snapshot = node.captureTransformSnapshot();  // { position, width, height, rotation, scale, skew, localBounds }
node.applyResize(snapshot, update);          // update = { position, width, height, localBounds }
node.applyAnchorChange(nextAnchor);          // 修改锚点并补偿 position，保持图形相对静止

captureTransformSnapshot() 返回的 scale / skew 均为 {x, y} 对象。applyAnchorChange 以当前锚点为基准做增量补偿，拖拽过程中可逐帧重复调用；内部几何随 position 联动的图元（如 Polyline）必须重写此方法。

绘制 ​

ts
draw(ctx, view);   // 处理 opacity / blendMode / 滤镜 / 阴影 / 裁剪后调用 _draw

子类实现 _draw(ctx, view) 完成具体绘制。滤镜 API 有两代：

ts
// 滤镜效果（推荐）：纯 JSON 描述，可序列化，支持 Worker / WebGL 加速
node.filterEffects([{ type: 'blur', params: { radius: 4 } }]);
node.filterEffects();                    // 读取（返回副本）
node.filterEffects(null);                // 清除
node.getFilterEffects();                 // 同 filterEffects()
node.setFilterEffects(effects);          // 同 filterEffects(effects)

// 滤镜类（旧版）：Filter 类数组 + 同名样式键传参
node.filters([Blur, Grayscale]);   // Filter[] | null，读取时省略参数

FilterDescriptor = { type, params?, enabled?, backend? }；描述必须是可 JSON 序列化的纯数据（filterEffects(value) 会校验并克隆）。内置效果类型与参数见 样式系统：滤镜与混合，自定义效果见 工具函数：滤镜效果注册。

连接器 ​

ts
node.getConnectors();   // 连接到本节点的 Connector 列表

Connector.setStart(node) / setEnd(node) 会在节点上注册引用；节点销毁时自动解绑。

宿主吸附（Host） ​

HT 风格吸附关系：节点可吸附到一个**宿主（host）**节点上，宿主平移 / 旋转时吸附节点自动跟随；宿主尺寸或缩放变化时，按 layoutH / layoutV 布局约束重算吸附节点的位置与尺寸。吸附关系与 Group 的 parent/children 层级互相独立。

ts
node.setHost(host);        // 吸附到宿主（null 解除吸附）
node.getHost();            // 当前宿主（null 表示未吸附）
host.getAttaches();        // 吸附在 host 上的节点列表
node.isHostOn(other);      // other 是否在 node 的宿主链上（防止成环）
node.isLoopedHostOn(other) // 双向宿主环检测
  • 宿主调用 setPosition / setX / setY 时，吸附节点保持相对偏移同步平移。
  • 宿主旋转时，吸附节点绕宿主中心旋转，自身旋转角同步累加。
  • 宿主尺寸 / 缩放 / 锚点变化时，按吸附节点的 layoutH / layoutV 样式执行 layout()。
  • setHost 拒绝成环：不能把自己设为自己的宿主，宿主链上已有节点也会被拒绝。
  • 宿主关系序列化为 props.host = { id }（见 序列化）。

布局约束样式 ​

样式取值说明
layoutHleft / right / center / leftright / scale相对宿主锚点的水平约束：固定左 / 右 / 中边距；leftright 左右固定并随宿主宽度拉伸；scale 按宿主宽度等比缩放
layoutVtop / bottom / center / topbottom / scale垂直方向同构：固定上 / 下 / 中边距；topbottom 上下固定并随宿主高度拉伸；scale 按宿主高度等比缩放
ts
const host = new Shape(); host.setSize(200, 100);
const child = new Shape(); child.setSize(20, 20);
child.setHost(host);
child.s('layoutH', 'left');        // 左侧固定
child.s('layoutV', 'topbottom');   // 上下固定并拉伸

host.setSize(300, 200);            // child 高度随宿主拉伸，左边距保持不变
  • 布局基于宿主锚点：如 layoutH: 'left' 表示吸附节点左边缘与宿主锚点左侧保持固定边距。
  • leftright / topbottom 在宿主单轴拉伸时会同步改变吸附节点的尺寸；吸附节点自身有旋转时，拉伸会按旋转角度投影到其宽 / 高上。
  • scale 保持吸附节点相对宿主的比例（位置与尺寸同步缩放）。
  • 吸附节点自身位置 / 尺寸变更会通过 updateLayoutParameters() 重新记录边距参数，下次宿主几何变化时按新基准布局。

全屏适配 ​

样式取值说明
fullscreenfill / uniform渲染前把节点铺满视口：fill 拉伸填满；uniform 按自身宽高比等比完整显示（居中）
ts
background.s('fullscreen', 'fill');      // 背景图拉伸铺满画布
logo.s('fullscreen', 'uniform');         // Logo 等比完整显示在画布中央
  • 由 ViewRenderer 在每帧渲染前执行布局，节点位置 / 尺寸被实时覆盖为视口适配值。
  • fullscreen: 'fill' 在编辑模式下不生效（保留原始几何，便于选中与调整）；退出编辑进入预览 / 运行模式恢复适配。
  • 全屏适配优先级高于画布级 fitContent 自动适配：存在 fullscreen 节点时，View 不再执行内容适配（见 View.isZoomable）。
