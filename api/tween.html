Tween 与动画 ​

Tween ​

全局 RAF 驱动的补间系统（TweenManager 单例）。

ts
import { Tween, Easing } from '@leaf-plus/core';

const tween = new Tween({ x: 0, y: 0 });
tween
  .to({ x: 100, y: 200 }, 600)
  .easing(Easing.cubicOut)
  .onStart((target) => console.log('start', target))
  .onUpdate((target, progress) => {
    shape.setPosition(target.x, target.y);
  })
  .onComplete(() => console.log('done'))
  .start();

Tween API ​

方法说明
to(properties: Partial<T>, duration = 1000): this定义补间目标（仅 number 属性参与插值）
easing(fn: EasingFunction): this缓动函数
delay(ms): this启动延迟
repeat(times): this重复次数，< 0 为无限循环
yoyo(enable = true): this往返补间
chain(...tweens: Tween[]): this串联后续补间
onStart / onUpdate / onComplete / onStop / onRepeat(cb): this生命周期事件
start(time?): this开始（缺省 performance.now()）
stop(): this停止
pause(): this / resume(): this暂停 / 继续
isPlaying(): boolean播放中？
getTarget(): T目标对象

tweenManager ​

ts
import { tweenManager } from '@leaf-plus/core';

tweenManager.update(performance.now());  // 手动推进调度（测试 / 自定义循环）
tweenManager.stopAll();
tweenManager.count();

每个 start() 的 Tween 会自动注册到管理器；停止后自动移除。

动画效果注册（全局） ​

ts
import {
  registerAnimationEffect,
  unregisterAnimationEffect,
  getAnimationEffect,
  getAnimationEffectMetas,
  createBuiltinAnimationIcon,
  createBuiltinAnimationDefinition,
  getBuiltinAnimationImageName,
  getBuiltinAnimationImages,
  getBuiltinAnimationType,
  isBuiltinAnimationImage,
  resolveAnimationValue,
} from '@leaf-plus/core';
函数说明
registerAnimationEffect(meta, effect)注册动画效果（手动管理，插件注册的自动回滚）
unregisterAnimationEffect(type)注销
getAnimationEffect(type)查效果
getAnimationEffectMetas()全部效果元信息（参数表单渲染用）
createBuiltinAnimationDefinition(type)按效果元信息默认值构造 ElementAnimation
createBuiltinAnimationIcon(type, options?)创建由 bind / attr 驱动的内置动画图标
getBuiltinAnimationImageName(type)动画类型 → 内置图片资源名
getBuiltinAnimationImages()内置动画图片清单
getBuiltinAnimationType(imageName)图片资源 → 动画类型
isBuiltinAnimationImage(name)是否内置动画图片
resolveAnimationValue(binding, element, view)解析 AnimationBinding（static / func）
setAnimationWorkerEnabled(enabled)全局启停内置重型动画的 Worker 图集加速（默认开启；关闭立即释放全部 Worker）
isAnimationWorkerEnabled()Worker 加速开关状态
isAnimationWorkerAvailable(view)指定 View 是否实际启用 Worker 图集（环境不支持时自动回退主线程）

在元素上应用动画 ​

ts
import { createBuiltinAnimationIcon, getBuiltinAnimationParamAttr } from '@leaf-plus/core';

const img = createBuiltinAnimationIcon('plasmaAnimation');
img.a(getBuiltinAnimationParamAttr('emissionRate'), 40);
storage.add(img);

ElementAnimation：{ id?, type, enabled?, play?, speed?, quality?, params? }。动画统一由 View 的渲染循环驱动（内置效果的图片在绘制期间更新）。内置动画类型清单见 动画系统。
