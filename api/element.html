Element ​

所有元素的基类。提供样式系统、属性系统、父子树与变换缓存。

子类：Node（→ Shape/Text/Image/Polyline/Group）、Connector。

ts
abstract class Element { /* 通过图元类实例化 */ }

样式系统 ​

ts
s(key: string, value?: any): any;
s(styles: Record<string, any>): any;
  • 单键赋值返回 this（可链式）；批量赋值返回 null（不可链式）；单键读取返回解析后的样式值。
  • _pickStyles(keys)：按图元类型批量取样式（图元绘制内部使用）。
ts
shape.s('background', '#fff');
shape.s({ background: '#fff', borderColor: '#000' });
shape.s('background');

属性系统 ​

ts
a(key: string, value?: any): any;   // 同上，业务属性
  • 读写任意业务键值（无强类型约束，Record<string, any>）。
  • Image.getAttr() 在属性缺失时会回退到矢量资源的 bind 默认值。
  • 序列化时写入元素的 attrs 字段。

身份与标签 ​

方法说明
getId() / setId(id)元素 id（storage 内唯一）
getTag() / setTag(tag)业务标签（可重复；storage.getElementByTag 查询）
getTypeName()类型名（如 'Shape'）
getLayer() / setLayer(name)图层归属

父子树 ​

ts
getParent() / setParent(el | null)
addChild(child)       // 追加子元素
removeChild(child)
getChildren()

父链变化自动级联：子元素的世界矩阵依赖父链，父节点的 _invalidateTransform() 会递归传播到所有子孙。按 id 查询子节点是 Group.getChildById(id)（Group 特有）。

树遍历与克隆 ​

ts
traverse(visitor: (el) => void)   // 深度优先遍历自身与子孙
find(predicate)                   // 返回第一个匹配的元素（含自身）
findAll(predicate)                // 返回全部匹配元素
clone()                           // 深拷贝（含样式/属性/子元素）
ts
group.traverse((el) => console.log(el.getTypeName()));

const firstShape = group.find((el) => el.getTypeName() === 'Shape');
const allImages = group.findAll((el) => el.getTypeName() === 'Image');

// 深拷贝：样式、属性、动画、图层与子元素一并复制；
// id 不复制（新元素获得新 id），tag 有意不复制以避免查询冲突
const copy = shape.clone();
storage.add(copy);

变换缓存 ​

ts
_invalidateTransform()  // 版本号 +1（级联子元素）
setCache(name, value)   // 存储缓存值（绑定当前版本）
getCache(name)          // 版本匹配才返回

缓存条目：matrix、worldMatrix、boundingBox、obb、pathWorldBounds、pathGeometry、sourcePathGeometry。

变更事件 ​

ts
emitChange(property: string, oldValue: unknown, newValue: unknown);
  • 通知 Storage 发出 elementChange，View 据此重绘。
  • 常用 setter 内部均调用；自定义 setter 需手动触达。
ts
class Gauge extends Shape {
  private _value = 0;

  setValue(v: number) {
    const oldValue = this._value;
    this._value = v;
    this.emitChange('value', oldValue, v);   // 触发 elementChange → View 重绘
  }
}

元素级事件订阅 ​

ts
el.on('change', (payload) => {})            // 任意属性变更
el.on('change:s:background', (payload) => {}) // 精确到样式键
el.off(event, handler) / el.once(event, handler)

元素自身是事件发射器（Emitter），无需经过 View；交互事件（点击/拖拽等）仍通过 view.onElementEvent 订阅。

动画 ​

ts
getAnimations(): ElementAnimation[]
setAnimations(animations: ElementAnimation[] | null | undefined)
ts
img.setAnimations([
  { id: 'a1', type: 'radarAnimation', enabled: true, play: true, speed: 1, params: {} },
]);
img.setAnimations(null);   // 清除全部动画定义
  • 动画定义包含 { id, type, enabled, play, speed, params } 字段。
  • setAnimations 在槽位或类型变化时释放效果运行状态；仅调整 play / speed / params 会保留状态（暂停可停留在当前帧）。
  • 动画类型与参数见 动画指南。

序列化 ​

序列化/反序列化由 Storage.serialize() / Storage.deserialize() 统一承担（见 Storage 与 序列化指南）：props 中的 { id } 引用（如 Connector 的 start / end）在 Storage 层解析为元素实例，元素自身不提供序列化钩子。

销毁 ​

ts
destroy();

销毁时释放子元素、连接器的引用绑定与事件监听（_destroyTree 由 Storage 统一调用）。
