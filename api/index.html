API 总览 ​

Leaf Plus 通过单入口导出全部公共 API。默认入口指向 TypeScript 源码；预构建产物使用子路径（详见 快速开始）。

滤镜 ​

ts
// 旧版滤镜类（filters([...]) + 同名样式键传参）
Blur, Brightness, Contrast, Grayscale, Glitch, HueRotate,
Invert, Noise, Pixelate, Saturate, Sepia
BUILTIN_FILTERS            // 名字 → 滤镜类的映射
getBuiltinFilter(name)
getBuiltinFilterName(filter)

// 滤镜效果（filterEffects，推荐，35 种内置效果类型）
registerFilterEffect(definition)   // 注册自定义效果
unregisterFilterEffect(type)
getFilterEffect(type)

类型: Filter, BuiltinFilterName
类型: FilterDescriptor, FilterBackend, FilterOutset, FilterDefinition, FilterParameterValue

内置效果类型清单见 样式系统：滤镜与混合。
