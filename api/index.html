API 总览 ​

Leaf Plus 通过单入口导出全部公共 API。默认入口指向 TypeScript 源码；预构建产物使用子路径（详见 快速开始）。

主类 ​

符号类型描述文档
Storageclass数据模型：元素管理、序列化、图层、历史Storage
Viewclass渲染器 + 交互控制器View
Elementclass元素基类Element
Nodeclass变换节点 / 包围盒几何Node
Shapeclass图形图元primitives
Textclass文本图元primitives
RichTextclass富文本图元（多段落 / 行内多样式 run / 超链接 / 滚动）primitives
Imageclass图像 / 矢量图标图元primitives
Polylineclass折线 / 路径图元primitives
Connectorclass连接线Connector
Groupclass组合容器Group
Componentclass矢量图标内可编辑组件Group
Clip / Restoreclass矢量图标裁剪标记Group
Emitterclass事件发射器View
Tween / tweenManagerclass / 单例实例补间动画（事件常量 TWEEN_EVENTS）Tween
Easingconst缓动函数集Tween
InteractionStatesconst交互状态常量View
ElementEventBinderclass声明式事件绑定（interactive / events props）交互与事件
ClipboardControllerclass画布剪贴板（复制 / 粘贴，跨 View 共享）交互与事件

滤镜 ​

ts
// 旧版滤镜类（filters([...]) + 同名样式键传参）
(Blur,
  Brightness,
  Contrast,
  Grayscale,
  Glitch,
  HueRotate,
  Invert,
  Noise,
  Pixelate,
  Saturate,
  Sepia);
BUILTIN_FILTERS; // 名字 → 滤镜类的映射
getBuiltinFilter(name);
getBuiltinFilterName(filter);

// 滤镜效果（filterEffects，推荐，35 种内置效果类型）
registerFilterEffect(definition); // 注册自定义效果
unregisterFilterEffect(type);
getFilterEffect(type);

类型: (Filter, BuiltinFilterName);
类型: (FilterDescriptor,
  FilterBackend,
  FilterOutset,
  FilterDefinition,
  FilterParameterValue);

内置效果类型清单见 样式系统：滤镜与混合。
