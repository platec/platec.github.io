样式配置项 ​

本文是 guide/styles 的完整对照表。所有样式通过 element.s(key, value) 读写，默认值按「实例样式 → 类型默认 → 全局默认 → 插件默认」解析（见 样式系统）。

图元的类型默认值定义在 DEFAULT_STYLES（src/constants.ts），全局类型 ElementStyles 声明于 src/types/globals.ts。下表键名与源码完全一致。

布局（Node） ​

宿主吸附（Host）相关的布局约束，仅在节点存在宿主（setHost）或开启全屏适配时生效：

键默认值类型说明
fullscreen—'fill' | 'uniform'渲染前铺满视口：fill 拉伸填满、uniform 等比完整显示（居中）。编辑模式下 fill 不生效，保留原始几何
layoutH—'left' | 'right' | 'center' | 'leftright' | 'scale'相对宿主锚点的水平约束：固定左 / 右 / 中边距；leftright 左右固定并随宿主宽度拉伸；scale 等比缩放
layoutV—'top' | 'bottom' | 'center' | 'topbottom' | 'scale'垂直方向同构：固定上 / 下 / 中边距；topbottom 上下固定并随宿主高度拉伸；scale 等比缩放

详见 API 参考：Node 宿主吸附。

命名渐变配置 ​

gradient（linear / radial / spread） ​

前缀方向色标
linear.*north / south / west / east / northeast / northwest / southeast / southwest[0, gradientColor → 1, background]
radial.center中心（cx: 0.5, cy: 0.5）中心 gradientColor → 边缘 background，初始半径 0
radial.*上表 8 个方向（圆心偏移 0.25/0.75）同上；初始半径 min(w,h)/24，终半径 max(w,h)/2
spread.horizontal / vertical / diagonal / antidiagonal对称带[0, background, 0.5, gradientColor, 1, background]
spread.north / south / west / east外扩对称[0, background, 1/3, gradientColor, 2/3, background, 1, gradientColor]，起终点外扩 1/4 尺寸
ts
shape.s({ background: '#fff', gradient: 'linear.north', gradientColor: '#2a7f72' });
shape.s({ background: '#fff', gradient: 'spread.horizontal', gradientColor: '#f00' });

*GradientPack（数组 / 字符串） ​

gradientPack、foregroundGradientPack、borderGradientPack、dashGradientPack 共用：

ts
// linear：起点 → 终点（坐标 0–1 归一化），后接成对 [偏移, 颜色]
shape.s({ background: '#fff', gradientPack: ['linear', 0, 0, 1, 1, 0, '#f00', 0.5, '#ff0', 1, '#0f0'] });

// radial：圆心 + 半径（相对 min(w,h)）+ 成对色标
shape.s({ background: '#fff', gradientPack: ['radial', 0.5, 0.5, 0.8, 0, '#f00', 1, '#0f0'] });

// 字符串：直接作为 fillStyle / strokeStyle 使用
shape.s({ borderGradientPack: 'linear-gradient(#000, #fff)' });

labelPosition（HT 1–55 位置系统） ​

labelPosition 取 1–55：每个位置对应元素包围盒上的锚点（x/y 比例 0–0.25–0.5–0.75–1 的组合）与标签盒的挂靠边（left/center/right × top/middle/bottom）。常用值：

值位置值位置
1 / 34 / 2左上角三态14 / 15 / 16左侧三态
3上边中部17居中（默认）
4 / 35 / 5右上角三态18 / 19 / 20右侧三态
7顶中27下边中部
23底中偏下15左中

完整映射见 src/draw/label.ts 的 POSITION_SPECS。
