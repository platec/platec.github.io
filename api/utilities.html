工具函数 ​

Leaf Plus 导出一批可直接使用的工具函数（无需 Storage / View 上下文）。

配置 ​

ts
import { defineConfig } from '@leaf-plus/core';

defineConfig({
  defaultStyles: { Shape: { pixelPerfect: true } },   // 全局样式默认值
  defaultVectorStyles: { ... },                        // 矢量符号默认样式
  rewriteURL: (url) => url.replace(/^asset:/, '/assets/'),  // 资源 URL 改写
});

自定义元素类型 ​

ts
import { registerElementType } from '@leaf-plus/core';

registerElementType('MyShape', MyShapeClass);   // 反序列化反射用

资源管理 ​

函数说明
setImage(name, source)注册图片资源（URL / SVG / data URI / 对象）
getImage(name)读取（ImageBitmap / HTMLImageElement / 矢量描述）
updateVectorImage(name, json)更新矢量符号资源
updateComponent(name, json)更新矢量资源中的组件
releaseImage(name)释放资源
clearImageCache()清空全部缓存
loadResource(path)加载单个资源（Promise）
loadResources(paths)批量加载（Promise.all）
resourceLoadedEmitter加载完成事件发射器

独立绘制 ​

ts
import {
  drawShapeStandalone, drawTextStandalone, drawPolylineStandalone,
  drawImageStandalone, drawStretchImageStandalone,
} from '@leaf-plus/core';

drawShapeStandalone(ctx, x, y, width, height, styles?, element?, view?);
drawTextStandalone(ctx, x, y, width, height, styles?, element?, view?);
drawPolylineStandalone(ctx, points?, segments?, closePath?, styles?, element?, view?);
drawImageStandalone(ctx, image, x, y, width, height, element?, view?);
drawStretchImageStandalone(ctx, image, x, y, width, height, imageStretch?, element?, view?);

辅助：resolveDrawStyles(...)（解析样式表）、createBindingHost(...)（属性绑定宿主）。

ts
registerHTMLRenderer(name, renderFnOrDefinition);
unregisterHTMLRenderer(name);
getRegisteredHTMLRenderer(name);

几何与路径 ​

ts
createPathGeometry(points, segments?, closed?, coordinateSpace?)  // 构建路径几何
collectPathControlPoints(...)
computePathBounds(...) / expandPathBounds(...)
tracePathGeometry(...) / transformPathGeometry(...)
createPathWalker(geometry, curveSteps = 24)              // 弧长采样器
EDGE_STYLES                                              // { straight, orthogonal, elbow, entityRelation }

createPathWalker 返回：{ length, pointAt(distance): { x, y, angle } } —— 按弧长取路径点与切线角（流动线插件的基础设施）。

选择 / 变换几何 ​

ts
clipPolygonByRect(...)          // 多边形被矩形裁剪
getOBBCorners(obb)              // OBB 四角
isOBBMostlyInsideRect(...)      // OBB 是否大部分在矩形内
obbCoverageByRect(...)          // 覆盖率
polygonArea(...)                // 多边形面积（框选）
getOppositeHandlePoint(...)     // 缩放手柄对角
getResizePositionDelta(...)     // 缩放位移
