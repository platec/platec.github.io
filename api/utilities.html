工具函数 ​

Leaf Plus 导出一批可直接使用的工具函数（无需 Storage / View 上下文）。

配置 ​

ts
import { defineConfig } from '@leaf-plus/core';

defineConfig({
  defaultStyles: { Shape: { pixelPerfect: true } },   // 全局样式默认值
  defaultVectorStyles: { ... },                        // 矢量符号默认样式
  rewriteURL: (url) => url.replace(/^asset:/, '/assets/'),  // 资源 URL 改写
});

registerHTMLRenderer('kpi-card', {
  render: (element, view) => {
    const div = document.createElement('div');
    div.textContent = `KPI: ${element.a('value') ?? 0}`;
    return div;
  },
  update: (dom, element) => {
    /* 键变化时原地更新 DOM */
  },
  dispose: (dom) => dom?.remove(),
  keys: ['value'], // 仅这些 attr 键变化才刷新

几何与路径 ​

ts
createPathGeometry(points, segments?, closed?, coordinateSpace?)  // 构建路径几何
collectPathControlPoints(...)
computePathBounds(...) / expandPathBounds(...)
tracePathGeometry(...) / transformPathGeometry(...) / getPath2D(...)
createPathWalker(geometry, curveSteps = 24)              // 弧长采样器
EDGE_STYLES                                              // { straight, orthogonal, elbow, entityRelation }

createPathWalker 返回：{ length, pointAt(distance): { x, y, angle } } —— 按弧长取路径点与切线角（流动线插件的基础设施）。

ts
const geometry = createPathGeometry(
  [
    { x: 0, y: 80 },
    { x: 40, y: 0 },
    { x: 120, y: 0 },
    { x: 160, y: 80 },
  ],
  [1, 4], // moveTo + bezierCurveTo（消费后续 3 个点）
  false,
);
const walker = createPathWalker(geometry);
const mid = walker.pointAt(walker.length / 2); // 路径中点：{ x, y, angle }

按需懒加载一个 stencil 类目（绘制到该前缀的形状时也会自动触发加载）：

ts
import {
  setStencilBaseUrl,
  registerStencilCategory,
  loadStencilCategory,
} from '@leaf-plus/core';

setStencilBaseUrl('/assets/stencils/');
registerStencilCategory({
  name: 'flowchart', // 类目名
  file: 'flowchart.xml', // 相对 baseUrl 的 XML 文件
  prefix: 'mxgraph.flowchart', // 形状名前缀（shape: 'mxgraph.flowchart.xxx'）
});
await loadStencilCategory('flowchart');

直接注册单条 stencil XML 定义：

ts
import { registerStencil } from '@leaf-plus/core';

registerStencil('my-shape', '<shape name="my-shape" ...>...</shape>');
shape.s('shape', 'stencil:my-shape');

滤镜效果注册 ​

ts
import {
  registerFilterEffect,
  unregisterFilterEffect,
  getFilterEffect,
  type FilterDefinition,
} from '@leaf-plus/core';

registerFilterEffect(definition) 注册自定义滤镜效果，之后任何节点都可以通过 node.filterEffects([{ type: 'myEffect', params: {...} }]) 使用：

ts
registerFilterEffect({
  type: 'myInvert',
  defaults: { amount: 1 }, // 参数默认值
  normalize: (params) => ({ ...params }), // 可选：参数规整 / 钳制
  getOutset: (params) => 0, // 可选：渲染边界外扩量（px 或 {left,top,right,bottom}）
  applyCPU: (imageData, params, node) => {
    // 必选：CPU 实现，原地修改像素
    const d = imageData.data;
    for (let i = 0; i < d.length; i += 4) {
      d[i] = 255 - d[i];
      d[i + 1] = 255 - d[i + 1];
      d[i + 2] = 255 - d[i + 2];
    }
  },
});

FilterDefinition 字段：

字段说明
type效果类型名（唯一，unregisterFilterEffect(type) 注销）
defaults参数默认值表
normalize(params)参数规整（钳制范围等），执行前调用
getOutset(params)会向外扩展像素的效果返回外扩量，用于渲染边界与裁剪
applyCPU(imageData, params, node?)CPU 实现（必选），原地修改 ImageData
gpu可选：WebGL 执行器认识的操作标识（内置效果使用）
spatial可选：标记结果依赖邻域像素（影响调度）
rasterParams可选：以逻辑像素给出、执行前需换算为栅格像素的参数名
resourceParam可选：URL / data-URL 参数名，由 Worker 解码缓存
workerSafe可选：标记该定义已注册进滤镜 Worker，可异步执行

自定义效果若未注册进内置 Worker（workerSafe 不为 true），滤镜链会回退到主线程同步执行。

import {
  hasGeometryCapability,
  hasPathGeometryCapability,
  createPathWalker,
} from '@leaf-plus/core';

if (hasGeometryCapability(el)) {
  console.log(el.getBoundingBox());
}
if (hasPathGeometryCapability(el)) {
  const walker = createPathWalker(el.getPathGeometry());
  console.log('路径总长', walker.length);
}

标尺 / 刻度 ​

为标尺、网格提供「nice step」刻度计算、数值格式化与配色主题（自绘标尺 / 网格时使用）。

ts
import {
  getRulerStep,
  formatRulerValue,
  resolveRulerTheme,
  RULER_THEMES,
} from '@leaf-plus/core';

// 按缩放选择约 targetPixels 像素一格的 1 / 2 / 5 × 10ⁿ 世界刻度
const step = getRulerStep(view.getViewportTransform().scale, 80);

// 刻度数值格式化（自动按 step 决定小数位）
formatRulerValue(120, step); // → '120'

// 主题配色：内置名 'light' / 'dark'，或部分覆盖内置浅色的自定义对象
const theme = resolveRulerTheme('dark'); // { background, border, tick, label, corner }
API说明
getRulerStep(scale, targetPixels = 80)选择约 targetPixels 像素一格的 1/2/5×10ⁿ 世界主刻度
formatRulerValue(value, step)按 step 的量级自动决定小数位，格式化刻度数值
resolveRulerTheme(theme?)把主题名 / 部分配色解析为完整 RulerThemeColors
RULER_THEMES内置 light / dark 配色表
