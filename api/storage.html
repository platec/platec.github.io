Storage ​

数据模型。持有所有 Element 实例，管理序列化 / 反序列化、图层、排序、撤销重做与批量事务，并发出变更事件。

ts
new Storage();

构造可选参数为空（默认元素列表 + 默认图层 + 空 attr）。

元素增删 ​

方法说明
add(data: Element, index?)加入元素（绑定 storage、打索引），触发 storageChange{type:'add'}
addAll(elements: Element[])批量加入（包 batch）
remove(data: Element)移除元素，触发 storageChange{type:'remove'}
removeAll(elements: Element[])批量移除
clear(silent?)清空（silent=true 不触事件）
getElements()全部元素（插入序）
getElementsInRenderOrder()按图层排序的渲染序（带缓存）
getElementCount()数量
getElementById(id)O(1) 按 id 查询
getElementByTag(tag)按 tag 查询
getElementsByType(type)按类型查询
getElementsByLayer(name)按图层查询
ts
storage.on('storageChange', (arg) => {
  if (arg.type === 'add') console.log('加入元素', arg.data);
  if (arg.type === 'remove') console.log('移除', arg.data);
});

图层 ​

ts
storage.getLayers();
storage.setLayers([{ name: '0', visible: true, selectable: true, movable: true, editable: true }]);
storage.getLayer(name?);
storage.getElementLayer(element);

Layer：{ name, visible, selectable, movable, editable }。构建器（编辑器的工具面板）操作图层时可用：

ts
const el = storage.getElements()[0];
el.setLayer('2');

分组 ​

ts
const group = storage.groupElements([a, b]);   // 按渲染顺序组合，返回 Group
const elements = storage.ungroupElements([group]); // 解组（保持画面不跳变，参数为元素数组）

排序 ​

方法说明
moveToTop(data: Element | Element[])置顶
moveToBottom(data)置底
moveUp(data)上移一层
moveDown(data)下移一层
ts
storage.moveToTop(shape);         // 单个置顶
storage.moveToBottom([a, b]);     // 支持数组批量操作
storage.moveUp(shape);            // 与上一个元素交换渲染顺序

排序变化触发 storageChange { type: 'reorder' }。

批量事务 ​

ts
storage.batch(() => {
  shape.setPosition(100, 200);
  shape.setSize(200, 100);
});

batch 期间所有变更合并为一次 elementChange{property:'__batch__', changes:[...]} + storageChange{type:'batch'}，只触发一次重绘。

历史记录（撤销 / 重做） ​

ts
storage.enableHistory(true, 100);   // 开启，上限 100 条；第三个参数为历史内存字节上限（默认 64MB，按各条目新增内容估算，超限淘汰最旧条目）
storage.isHistoryEnabled();
storage.undo();
storage.redo();
storage.canUndo();
storage.canRedo();
storage.clearHistory();
storage.beginHistoryTransaction();   // 交互操作前手动开事务
storage.endHistoryTransaction('interaction');
  • 触发 historyChange { canUndo, canRedo } 事件，UI 据此更新按钮。
  • 连续 drag 等操作会被自动合并为一条历史。
  • 历史条目对未变更元素做结构共享：快照成本与内存占用与变更量而非场景规模成正比，大图纸（数万图元）下记录开销为毫秒级。
ts
storage.on('historyChange', ({ canUndo, canRedo }) => {
  undoButton.disabled = !canUndo;
  redoButton.disabled = !canRedo;
});

// 手动事务：把一次交互（如拖拽）中的连续变更合并为一条历史
storage.beginHistoryTransaction();
element.setPosition(x1, y1);
element.setPosition(x2, y2);
storage.endHistoryTransaction();   // 默认 key 'interaction'，同 key 事务 500ms 内继续合并

背景与内容包围盒 ​

ts
storage.getBackground(); storage.setBackground('#fff');
storage.getContentRect(); storage.setContentRect(rect, { silent: true });
storage.recalculateContentRect();    // 由元素包围盒推导
storage.reconcileContentRect();      // 内容与存储值对齐（收敛算法）

属性（storage 级） ​

ts
storage.getAttr('doc'); storage.setAttr('doc', {...});
storage.setTransientAttr('temporary', value);  // 不进入序列化

运行 / 预览配置也通过 attrs 表达（View 读取，随序列化往返）：

属性类型说明
fitContentboolean非编辑模式下自动适配内容（View 在挂载 / 尺寸变化 / deserialize 时执行 fitContent）
zoomableboolean非编辑模式下允许缩放视口（缺省允许）
pannableboolean非编辑模式下允许平移视口（缺省允许）
ts
storage.setAttr('fitContent', true);   // 只读预览：打开图纸自动居中
storage.setAttr('zoomable', false);    // 锁定缩放
storage.setAttr('pannable', false);    // 锁定平移

见 API 参考：View 视口交互开关。

序列化 ​

ts
storage.serialize();             // 得到 JSON 对象
storage.deserialize(json | string | undefined);

详见 序列化与反序列化。

事件 ​

事件载荷说明
elementChange{ property, oldValue, newValue, data } 或 batch 载荷元素属性变更
storageChange{ type, ... }场景变更（add/remove/reorder/layers/background/contentRect/attr:*/batch/clear/deserialize/beforeDeserialize）
historyChange{ canUndo, canRedo }历史状态变化
ts
storage.on('elementChange', (arg) => {});
storage.once('storageChange', (arg) => {});
storage.off('elementChange', handler);

销毁 ​

ts
storage.destroy();   // 清空事件总线并释放全部元素
