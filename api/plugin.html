interface LeafPlugin {

PluginContext 能力 ​

能力签名说明
样式扩展registerStyleProperty({ key, defaultValue })element.s(key) 可读写的样式键 + 全局默认值；建议加前缀防冲突（如 flowReverse）
绘制装饰器registerDrawDecorator(decorator)元素绘制前后追加绘制（见下）
动画效果registerAnimationEffect(meta, effect)注册动画效果，随插件卸载
逐帧驱动requestFrame(view)每帧绘制后调用，驱动持续动画

DrawDecorator ​

ts
interface DrawDecorator {
  name?: string;
  appliesTo?: (element: Element) => boolean;   // false 则跳过
  beforeDraw?: (context: DrawDecoratorContext) => void;
  afterDraw?: (context: DrawDecoratorContext) => void;
}

interface DrawDecoratorContext {
  ctx: CanvasRenderingContext2D;   // 已应用元素的世界变换，与元素同坐标系
  element: Element;
  view: View;
}

要点：

  • 仅在主画布实时绘制中执行；交互拖拽缓存帧与像素命中帧不执行。
  • 按注册顺序执行（多个装饰器可叠加）。

AnimationEffect / Meta ​

ts
interface AnimationEffectMeta {
  type: string;                 // 效果名（如 'flow'）
  label: string;
  description?: string;
  parameters: AnimationParameterMeta[];
}

interface AnimationEffect {
  createState?: () => any;
  update?: (ctx: AnimationEffectContext) => void;
  beforeDraw?: (ctx: AnimationEffectContext) => void;
  afterDraw?: (ctx: AnimationEffectContext) => void;
  /** 返回 false 时效果仍绘制当前帧，但不再请求下一帧（用于一次性的效果自然结束） */
  isActive?: (ctx: AnimationEffectContext) => boolean;
  /** 效果超出元素矩形的最大局部距离，供视口裁剪外扩 */
  getRenderOutset?: (params: Record<string, any>, rect: AnimationRect) => number;
  dispose?: (state: any) => void;
}

AnimationEffectContext：{ ctx, element, view, rect, params, state, delta, elapsed, speed, quality, random }，其中 random 为确定性随机函数（同一效果重放结果可复现）。应用方式：element.setAnimations([{ type: 'flow', params: {...} }])。isActive 钩子与暂停语义见 动画指南。

flow 插件（leaf-flow） ​

ts
usePlugin(createFlowPlugin());

line.s({
  flow: true,
  flowStep: 6,
  flowCount: 2,
});

样式键默认值（FLOW_STYLE_DEFAULTS，共 27 键）：flow:false、flowReverse:false、flowAutoReverse:false、flowCount:1、flowStep:1.5、flowElementCount:32、flowElementBackground:'rgba(255, 255, 114, 0.4)'、flowElementMax:7、flowElementMin:0.45、flowElementSpace:0、flowElementAspect:4.6、flowShadowVisible:true、flowShadowBeginColor:'rgba(255, 255, 0, 0.3)'、flowShadowEndColor:'rgba(255, 255, 0, 0)'、flowShadowMax:22、flowShadowMin:4、flowLoop:true、flowUnit:'local'、flowElementOpacityStart:1、flowElementOpacityEnd:0.12、flowRenderMode:'droplet'、flowElementImage:''、flowIconCount:5、flowIconWidth:20、flowIconHeight:20、flowIconRotate:'path'、flowIconStretch:'uniform'。

flowRenderMode 支持 droplet（水滴）/ dots（圆点）/ trail（光带）/ both（水滴+光带）/ icon（图片图标）；flowUnit 支持 local / world / screen。

参考实现：packages/core/src/plugins/flow/（PathWalker 弧长采样 + afterDraw 装饰器 + requestFrame 逐帧驱动）。文档：packages/core/src/plugins/flow/README.md，示例 packages/core/examples/flow-plugin.html。

自定义插件完整示例 ​

ts
import type { LeafPlugin, PluginContext } from '@leaf-plus/core';

// 类型扩展（声明合并）
declare global {
  interface ElementStyles {
    myGlow?: boolean;
    myGlowColor?: string;
  }
}

const myPlugin: LeafPlugin = {
  name: 'my-plugin',
  install(context: PluginContext) {
    context.registerStyleProperty({ key: 'myGlow', defaultValue: false });
    context.registerStyleProperty({ key: 'myGlowColor', defaultValue: '#ffdd55' });

    context.registerDrawDecorator({
      name: 'my-glow',
      appliesTo: (element) => !!element.s('myGlow'),
      afterDraw: ({ ctx, element }) => {
        const b = element.getBoundingBox();
        ctx.save();
        ctx.globalAlpha = 0.35;
        ctx.fillStyle = element.s('myGlowColor');
        ctx.fillRect(b.x, b.y, b.width, b.height);
        ctx.restore();
      },
    });
  },
};

usePlugin(myPlugin);
shape.s('myGlow', true);
