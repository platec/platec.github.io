图元：Shape / Text / RichText / Image / Polyline ​

五个 Node 子类图元。所有图元继承 Node（→ Element）的全部能力：变换、样式、属性、父子树。

Shape —— 图形图元 ​

无专有方法，全部能力来自 Node + 样式系统。

形状名（样式键 shape）：

值形状
rect矩形
circle / oval圆形 / 椭圆
roundRect圆角矩形（cornerRadius）
star星形（starRatio / starSide）
pentagram五角星
triangle / pentagon / hexagon正多边形（regular 控制等边修正）
diamond菱形
rightTriangle直角三角形
parallelogram平行四边形
trapezoid梯形
polygon多边形（polygonSides）
arc扇形（arcFrom / arcTo / arcClose / arcOval）
nStarN 角星
stencil:<name>mxGraph Stencil 绘制
mxgraph.* / drawio 名mxgraph / drawio 扩展形状
ts
const shape = new Shape();
shape.setPosition(60, 140);
shape.setSize(120, 60);
shape.s({
  shape: 'roundRect',
  cornerRadius: 8,
  background: '#d8eee9',
  borderColor: '#2a7f72',
  borderWidth: 2,
  label: 'A',
});
storage.add(shape);

通用特征：渐变（gradient / gradientPack）、图片填充（backgroundImage / repeatImage）、前景层（foreground*）、描边变体（border3d / innerBorder / doubleBorder）、手绘（rough）。

Text —— 文本图元 ​

文本内容使用样式键 text，不是 props。

ts
const text = new Text();
text.setPosition(300, 100);
text.s({
  text: '你好，Leaf Plus！',
  font: '16px arial, sans-serif',
  color: '#334155',
  align: 'left',
  vAlign: 'middle',
});
storage.add(text);
专有 API说明
getWidth() / getHeight()覆写：未显式设置时默认 100 × 50
hitTest(point, ctx)覆写：pixelPerfect 时走像素命中

关键样式：text、font（或 fontSize/fontWeight/fontStyle/fontFamily）、color、background、outlineColor/outlineWidth、align/vAlign、vertical/verticalGap（竖排）、wrap、textOverflow ('visible'|'clip'|'ellipsis')、textPadding、lineHeight、letterGap、decoration、cornerRadius。

RichText —— 富文本图元 ​

Text 只能整块使用一种样式；RichText 支持多段落、每段落内多个行内 run，run 可各自设置颜色、字号、粗细、斜体、字间距、高亮底色、下划线 / 删除线以及超链接。内容本体存放在 props.content（不走样式通道），元素级样式作为 run / 段落未设置字段的回落默认值。

ts
import { RichText } from '@leaf-plus/core';

const rich = new RichText();
rich.setPosition(60, 50);
rich.setSize(420, 190);
rich.s({
  background: '#f8fafc',
  cornerRadius: 10,
  textPadding: 16,
  font: '15px system-ui, sans-serif',
  color: '#334155',
  wrap: true,
});
rich.setContent([
  {
    align: 'left',
    spaceAfter: 8,
    runs: [{ text: '标题', fontSize: 18, fontWeight: 700, color: '#0f766e' }],
  },
  {
    runs: [
      { text: '混排 ' },
      { text: '彩色', color: '#e11d48' },
      { text: '、' },
      { text: '高亮', highlight: '#fde68a', color: '#92400e' },
      { text: '、' },
      {
        text: '超链接',
        link: 'https://platec.github.io/',
        color: '#2563eb',
        textDecoration: 'underline',
      },
      { text: ' 文本。' },
    ],
  },
]);
storage.add(rich);

setContent 接受三种输入（RichTextContentInput），内部统一归一化为段落数组：

输入形态归一化结果
string单段落、单 run
RichTextRun[]单段落，多个行内 run
RichTextParagraph[]完整多段落结构

RichTextRun 字段：text、color、fontSize、fontWeight、fontStyle、fontFamily、letterSpacing、textDecoration（underline / line-through / overline，可数组组合）、highlight（文字底色）、link（超链接，非空时该 run 参与链接命中）。每个字段都支持数据绑定简写 { func: 'attr@name', value }。

RichTextParagraph 字段：runs、align（left / center / right）、lineHeight、spaceBefore、spaceAfter。未设置时回落到元素级样式。

专有 API说明
setContent(input) / getContent()设置 / 读取归一化后的段落内容
getRuns()绑定解析后的扁平 run 视图（命中 / 链接 / 导出用途）
getLinkAt(x, y)元素局部坐标下的链接命中，返回链接字符串或 null
getScrollY() / setScrollY(v)滚动偏移（textOverflow: 'scroll' 时，自动钳制到有效范围）
getScrollRange() / isContentScrollable()可滚动最大偏移 / 是否溢出可滚动
handleWheelScroll(deltaY)滚轮滚动内容，返回是否消费了该事件
getScrollbarGeometry() / hitTestScrollbar(x, y) / scrollbarDeltaToScroll(dy)滚动条几何与命中（自定义滚动条交互用）

链接命中传入的是元素局部坐标，从交互事件的世界坐标换算：

ts
rich.setInteractive(true);
view.onElementEvent(rich, 'click', (event) => {
  // invert() 会原地修改矩阵，先 clone 再求逆
  const local = rich
    .getWorldMatrix()
    .clone()
    .invert()
    .transformPoint(event.x, event.y);
  const link = rich.getLinkAt(local.x, local.y);
  if (link) window.open(link, '_blank');
});

内容溢出时开启滚动（配合固定高度）：

ts
rich.s({ textOverflow: 'scroll' }); // 溢出内容可滚动，绘制内置滚动条
rich.handleWheelScroll(40); // 交互层把滚轮增量转交给它

关键样式键（RICHTEXT_STYLE_KEYS 的常用项）：font、fontSize/fontWeight/fontStyle/fontFamily、color、background、cornerRadius、outlineColor/outlineWidth、align/vAlign、wrap、textOverflow ('visible'|'clip'|'ellipsis'|'scroll')、textPadding、lineHeight、letterGap、linkColor/linkDecoration。

Image —— 图像 / 矢量图标图元 ​

ts
import { Image } from '@leaf-plus/core';

const img = new Image();
img.setImage('element/icons/pump.svg'); // 资源名 | URL | data URI
img.setPosition(0, 0);
storage.add(img);
专有 API说明
setImage(source) / getImage()设置 / 读取图片资源
getImageResource()解析后的资源（{ image, ... }）
getAttr(key) / setAttr(key, value)覆写：缺失时回退矢量资源 bind 默认值
getWidth()/getHeight()/getSize()覆写：未设置时从资源固有尺寸同步
getRenderHTML() / setRenderHTML(def)HTML 叠加渲染定义
getAttachPoints()矢量资源中声明的吸附锚点
isDrawable() / isResourceReady()资源是否就绪（渲染前检查）
hasOwnAnimations() / hasEmbeddedAnimations() / managesOwnAnimations()动画归属判定
prepareRender(...)渲染前准备（解码 / 位图栅格化）
hitTest()覆写：内置动画 / renderHTML 按包围盒命中

getAttr / setAttr 的符号绑定语义（attr@ 表达式、bind[].defaultValue 兜底）见 图标绑定。

关键样式：imageStretch（fill | uniform | centerUniform | cover | center）、renderHTML。

内置动画图片：

ts
const img = createBuiltinAnimationIcon('plasmaAnimation');
img.a(getBuiltinAnimationParamAttr('speed'), 90);

Polyline —— 折线 / 路径图元 ​

ts
const poly = new Polyline();
poly.setPoints([
  { x: 0, y: 0 },
  { x: 80, y: 40 },
  { x: 160, y: 0 },
]);
poly.setClosePath(false);
poly.setSegments([]); // 默认全部隐式 lineTo
poly.s({ borderColor: '#2563eb', borderWidth: 3, borderJoin: 'round' });
storage.add(poly);
方法说明
setPoints(points) / getPoints()顶点集合
setSegments(segments) / getSegments()段类型编码（见下表）
setClosePath(bool) / getClosePath()闭合路径
setPoint(i, p) / setEditablePoint(i, p)编辑单点（editable 参与持久化）
addPoint(p, index?) / appendLinePoint(p)增点
removePointAt(i)删点
setControlPointMode(i, mode) / getControlPointMode(i)控制手柄模式（Bezier）
toggleAnchorCurve(i)切换锚点曲线
insertPointOnSegment(segIdx, t) / insertLinePointOnSegment(...)线段内插
getEditablePointInfo(i)点元信息
getLocalPathPoints()局部坐标顶点
getPathGeometry() / getSourcePathGeometry()路径几何（上下文不同）
getLength()弧长（供动画采样）
getPointAt(t)按比例 t (0–1) 取样点
getAnchorPointWorld()锚点世界坐标
getLogicalLocalRect()逻辑局部矩形（用于吸附）
containsPoint / hitTest覆写：路径本身参与像素级命中
setSize/w/h覆写：宽高 ≤ 0 时由点集推导并持续同步

segments 段类型编码：1 = moveTo、2 = lineTo、3 = quadraticCurveTo(消费 2 点)、4 = bezierCurveTo(消费 3 点)、5 = closePath；缺省（0 / 省略）为折线隐式 lineTo。

ts
poly.setPoints([
  { x: 0, y: 0 },
  { x: 50, y: 0 },
  { x: 50, y: 50 },
  { x: 100, y: 50 },
]);
poly.setSegments([1, 2, 3]); // moveTo + lineTo + quadTo

控制点模式（PolylineControlMode）：每个锚点的曲线手柄联动方式，由 setControlPointMode(anchorIndex, mode) 设置：

模式说明
line直线锚点：相邻曲线段降级为 lineTo
mirror镜像：两侧手柄共线且等长，拖动一侧另一侧对称跟随
asymmetric不对称：两侧手柄共线但长度独立
disconnected断开：两侧手柄完全独立

setControlPointMode 会自动在 lineTo / bezierCurveTo 段类型间转换并重建手柄几何，返回调整后的锚点索引（段编码变化可能引起索引位移）。toggleAnchorCurve(i) 在 line ↔ mirror 间切换（disconnected / asymmetric 先归一为 mirror）。配合 getEditablePointInfo(i)（区分锚点 / 手柄）、findEditableSegment(point, tolerance) 与 insertPointOnSegment(segIdx, t)（De Casteljau 分割，保形插点）可实现完整的可视化路径编辑。

ts
// 画一条平滑曲线：三个锚点，中间锚点转为镜像曲线
poly.setPoints([
  { x: 0, y: 80 },
  { x: 80, y: 0 },
  { x: 160, y: 80 },
]);
poly.setControlPointMode(1, 'mirror'); // 自动把相邻段升级为贝塞尔并生成对称手柄

// 在线段上保形插点：先找最近线段，再在 t 处分割
const hit = poly.findEditableSegment({ x: 42, y: 30 }, 8);
if (hit) poly.insertPointOnSegment(hit.segmentIndex, hit.t);

描边样式（键）：borderColor/borderWidth/borderJoin/borderCap/miterLimit/borderPattern/borderWidthAbsolute/dash/dashColor/dashWidth/dashOffset。Node.setStyle 覆写：样式值实际变化时递增滤镜缓存版本号，使滤镜缓存自动重建。
