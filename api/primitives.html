图元：Shape / Text / Image / Polyline ​

四个最常用的 Node 子类。所有图元继承 Node（→ Element）的全部能力：变换、样式、属性、父子树。

Shape —— 图形图元 ​

无专有方法，全部能力来自 Node + 样式系统。

形状名（样式键 shape）：

值形状
rect矩形
circle / oval圆形 / 椭圆
roundRect圆角矩形（cornerRadius）
star星形（starRatio / starSide）
pentagram五角星
triangle / pentagon / hexagon正多边形（regular 控制等边修正）
diamond菱形
rightTriangle直角三角形
parallelogram平行四边形
trapezoid梯形
polygon多边形（polygonSides）
arc扇形（arcFrom / arcTo / arcClose / arcOval）
nStarN 角星
stencil:<name>mxGraph Stencil 绘制
mxgraph.* / drawio 名mxgraph / drawio 扩展形状
ts
const shape = new Shape();
shape.setPosition(60, 140);
shape.setSize(120, 60);
shape.s({
  shape: 'roundRect',
  cornerRadius: 8,
  background: '#d8eee9',
  borderColor: '#2a7f72',
  borderWidth: 2,
  label: 'A',
});
storage.add(shape);

通用特征：渐变（gradient / gradientPack）、图片填充（backgroundImage / repeatImage）、前景层（foreground*）、描边变体（border3d / innerBorder / doubleBorder）、手绘（rough）。

Text —— 文本图元 ​

文本内容使用样式键 text，不是 props。

ts
const text = new Text();
text.setPosition(300, 100);
text.s({
  text: '你好，Leaf Plus！',
  font: '16px arial, sans-serif',
  color: '#334155',
  align: 'left',
  vAlign: 'middle',
});
storage.add(text);
专有 API说明
getWidth() / getHeight()覆写：未显式设置时默认 100 × 50
hitTest(point, ctx)覆写：pixelPerfect 时走像素命中

关键样式：text、font（或 fontSize/fontWeight/fontStyle/fontFamily）、color、background、outlineColor/outlineWidth、align/vAlign、vertical/verticalGap（竖排）、wrap、textOverflow ('visible'|'clip'|'ellipsis')、textPadding、lineHeight、letterGap、decoration、cornerRadius。

Image —— 图像 / 矢量图标图元 ​

ts
import { Image } from '@leaf-plus/core';

const img = new Image();
img.setImage('element/icons/pump.svg');   // 资源名 | URL | data URI
img.setPosition(0, 0);
storage.add(img);
专有 API说明
setImage(source) / getImage()设置 / 读取图片资源
getImageResource()解析后的资源（{ image, ... }）
getAttr(key) / setAttr(key, value)覆写：缺失时回退矢量资源 bind 默认值
getWidth()/getHeight()/getSize()覆写：未设置时从资源固有尺寸同步
getRenderHTML() / setRenderHTML(def)HTML 叠加渲染定义
getAttachPoints()矢量资源中声明的吸附锚点
isDrawable() / isResourceReady()资源是否就绪（渲染前检查）
hasOwnAnimations() / hasEmbeddedAnimations() / managesOwnAnimations()动画归属判定
prepareRender(...)渲染前准备（解码 / 位图栅格化）
hitTest()覆写：内置动画 / renderHTML 按包围盒命中

getAttr / setAttr 的符号绑定语义（attr@ 表达式、bind[].defaultValue 兜底）见 图标绑定。

关键样式：imageStretch（fill | uniform | centerUniform | cover | center）、renderHTML。

内置动画图片：

ts
img.setImage(getBuiltinAnimationImageName('fire'));
// createBuiltinAnimationDefinition(type) 只接受类型名，params 取效果元信息的默认值；
// 需要定制 speed / params 时显式构造动画定义对象：
img.setAnimations([{ id: 'fire-1', type: 'fire', speed: 2, params: {} }]);

Polyline —— 折线 / 路径图元 ​

ts
const poly = new Polyline();
poly.setPoints([{ x: 0, y: 0 }, { x: 80, y: 40 }, { x: 160, y: 0 }]);
poly.setClosePath(false);
poly.setSegments([]);   // 默认全部隐式 lineTo
poly.s({ borderColor: '#2563eb', borderWidth: 3, borderJoin: 'round' });
storage.add(poly);
方法说明
setPoints(points) / getPoints()顶点集合
setSegments(segments) / getSegments()段类型编码（见下表）
setClosePath(bool) / getClosePath()闭合路径
setPoint(i, p) / setEditablePoint(i, p)编辑单点（editable 参与持久化）
addPoint(p, index?) / appendLinePoint(p)增点
removePointAt(i)删点
setControlPointMode(i, mode) / getControlPointMode(i)控制手柄模式（Bezier）
toggleAnchorCurve(i)切换锚点曲线
insertPointOnSegment(segIdx, t) / insertLinePointOnSegment(...)线段内插
getEditablePointInfo(i)点元信息
getLocalPathPoints()局部坐标顶点
getPathGeometry() / getSourcePathGeometry()路径几何（上下文不同）
getLength()弧长（供动画采样）
getPointAt(t)按比例 t (0–1) 取样点
getAnchorPointWorld()锚点世界坐标
getLogicalLocalRect()逻辑局部矩形（用于吸附）
containsPoint / hitTest覆写：路径本身参与像素级命中
setSize/w/h覆写：宽高 ≤ 0 时由点集推导并持续同步

segments 段类型编码：1 = moveTo、2 = lineTo、3 = quadraticCurveTo(消费 2 点)、4 = bezierCurveTo(消费 3 点)、5 = closePath；缺省（0 / 省略）为折线隐式 lineTo。

ts
poly.setPoints([{x:0,y:0}, {x:50,y:0}, {x:50,y:50}, {x:100,y:50}]);
poly.setSegments([1, 2, 3]);   // moveTo + lineTo + quadTo

描边样式（键）：borderColor/borderWidth/borderJoin/borderCap/miterLimit/borderPattern/borderWidthAbsolute/dash/dashColor/dashWidth/dashOffset。Node.setStyle 覆写：样式值实际变化时递增滤镜缓存版本号，使滤镜缓存自动重建。
