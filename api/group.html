Group —— 组合容器 ​

Group 是 Node 子类：自身不绘制，只包含并渲染子节点。常用于「组合 / 解组」（storage.groupElements / ungroupElements）。

ts
const group = new Group();
group.add(shapeA);
group.addChildren([shapeB, textC]);
storage.add(group);
方法说明
add(child) / addChildren(children)加入子节点
remove(child) / setChildren(children)移除 / 重置子节点
getChildren()子节点数组
getChild(idOrIndex) / getChildById(id)查询
setSize(w, h) / getSize() / getWidth() / getHeight()尺寸（由子节点包围盒同步；setSize 按新旧尺寸比例缩放全部子节点以适配）
setChildrenPosition(x, y)批量移动
setChildrenSize / Scale / Rotation / Opacity批量变换
setChildrenFilters(filters)批量滤镜
translateChildren(dx, dy)相对平移子节点
applyResize / captureTransformSnapshot使用 Node 语义的缩放编辑
isDrawable()存在可绘制子节点时才绘制
onChildAdded / onChildRemoved / onDescendantChange子树变化回调（内部维护包围盒）

批量操作子节点的典型用法：

ts
group.translateChildren(10, 0);                 // 全部子节点平移
group.setChildrenOpacity(0.5);                  // 批量半透明
group.setChildrenRotation(Math.PI / 4);         // 批量旋转
group.setChildrenFilters(null);                 // 批量清除旧版滤镜

序列化：子节点通过 props.parent = { id } 或 Group 的 props.children 表达父子关系；Group 子对象的 props 中坐标可能是世界坐标（serialize 时转换——Storage.serialize 会在 Group 子节点写入世界坐标）。

Component —— 矢量组件 ​

Component 是矢量图标内的可编辑组件。矢量符号资源可以声明可替换/可绑定的组件位置：

ts
const component = new Component();
component.setComponent('pump');        // 绑定到资源中的组件槽位
component.setPosition(...); component.setSize(...);
方法说明
setComponent(name) / getComponent()组件名 / 槽位
setSize / setWidth / setHeight组件尺寸
prepareRender(ctx, view)渲染准备（与资源绑定联动）

配合 updateComponent(name, json) 可动态更新矢量资源中的组件定义。

Clip / Restore —— 矢量裁剪标记 ​

矢量符号（SVG → 数据中心化）中保留的裁剪语义：

类基类语义
ClipPolyline裁剪开始：用 points / segments 构成裁剪路径，绘制后 ctx.clip()
RestoreElement裁剪恢复：ctx.restore()

两者不参与编辑与命中检测（isSelectable() = false，选择模式为 'none'）。Clip 的 points 是图标坐标系中的绝对坐标（不允许 Polyline 的「缺尺寸自动推导」行为）。save/restore 生命周期由 ViewRenderer 管理，裁剪可跨元素生效：

ts
const clip = new Clip();
clip.setPoints([{ x: 0, y: 0 }, { x: 40, y: 0 }, { x: 40, y: 40 }, { x: 0, y: 40 }]);
clip.setSegments([]);   // 默认 rect 路径
storage.add(clip);
storage.add(restore);   // Restore 元素
