接线图演示 ​

本页将编辑器中的「接线图」图纸渲染到 Canvas 中，并通过定时器驱动图纸内 Image 对象的属性实时变化：

  • 每 2 秒为每个 Image 对象随机设置 value 属性（0–100 的随机小数）；
  • 同时随机设置 state 属性（true / false）；
  • 遥测类符号（有功遥测 / 无功遥测 / 其它遥测）通过属性绑定将 value 映射到文本显示，数值随之实时刷新；
  • 刀闸符号通过 state 控制刀刃开合（true 闭合、false 张开 30°）；
  • 安装 flow 流动线插件，为图纸中的 18 条连接线开启流动动画（沿路径步进的点阵拖尾）；
  • 图纸内全部图形开启 pixelPerfect 像素级命中检测。

实现要点 ​

图纸中的 Image 元素引用相对路径的矢量符号（symbols/图标库/电力/*.json）， 在子目录页面下需通过 defineConfig 的 rewriteURL 统一改写为站点根目录绝对路径：

ts
import { defineConfig } from '@leaf-plus/core';

defineConfig({
  rewriteURL: (url) => (/^(data:|https?:|\/)/.test(url) ? url : `/${url}`),
});

定时器驱动属性变化的核心逻辑：

ts
timer = window.setInterval(() => {
  for (const el of storage.getElements()) {
    if (el instanceof Image) {
      el.a('value', Math.random() * 100);
      el.a('state', Math.random() < 0.5);
    }
  }
}, 2000);

a(name, value) 写入属性时会触发 emitChange，View 自动重绘； 组件绑定表达式 attr@value 逐帧求值，符号文本随之更新。

flow 流动线动画 ​

安装 flow 插件后，为 Polyline 设置 flow 系列样式即可开启流动动画：

ts
import { Polyline, createFlowPlugin, usePlugin } from '@leaf-plus/core';

usePlugin(createFlowPlugin()); // 安装一次，全局生效

for (const el of storage.getElements()) {
  // 像素级命中检测：离屏 alpha 采样，透明镂空处可穿透选中
  el.s('pixelPerfect', true);
  if (el instanceof Polyline) {
    el.s({
      flow: true,
      flowStep: 1.5,
      flowElementCount: 14,
      flowElementMax: 3,
      flowElementMin: 0.25,
      flowElementAspect: 3.2,
      flowElementSpace: 0.8,
      flowElementBackground: 'rgba(255, 224, 90, 0.9)',
      flowShadowMax: 5,
      flowShadowMin: 0.4,
    });
  }
}

插件通过绘制装饰器沿 getPathGeometry() 返回的路径绘制流动元素， flowStep 控制流速（按 60fps 折算，帧率波动不影响速度）；仅在存在流动元素的 视图上请求动画帧，其他页面不受影响。样式键对齐 ht-flow 语义，详见 plugins 指南 与 src/plugins/flow/README.md。

数据来源 ​

图纸数据来自编辑器 packages/editor/public/displays/接线图/接线图.json （157 个元素：Image 103 / Text 19 / Polyline 18 / Shape 14 / Group 3）， 对应的电力符号库位于 packages/editor/public/symbols/图标库/电力/。
