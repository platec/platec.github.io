🍃

Storage + View 架构

数据模型与渲染分离。Storage 负责元素管理与序列化；View 负责 Canvas 渲染、视口变换与交互控制。

🖊

丰富的图元与样式

Shape / Text / Image / Polyline / Connector 等图元，支持渐变、图案、阴影、手绘、滤镜、内描边等数十种样式。

🔗

插件系统

通过 PluginContext 扩展样式属性、绘制装饰器与动画效果，卸载时自动回滚注册内容。

♻️

序列化 / 反序列化

场景图一键导出 JSON，支持自定义元素类型注册与完整往返还原。

🎞️

动画与补间

内置 Tween 补间系统、内置动画效果（动画图片）、流动线插件等。

📐

布局与全屏适配

宿主吸附（Host）与 layoutH/layoutV 布局约束，fullscreen 视口全屏适配，预览模式可配置自动适配 / 锁定缩放平移。

🎛

完整的交互

鼠标 / 触摸 / 手势事件、元素级事件冒泡、像素级命中检测、声明式事件绑定。

🛠

开箱即用的编辑器

基于核心库构建的图形编辑器，支持图纸 / 图标 / 组件编辑与 Mermaid / DXF / SVG / drawio 导入。访问 platec.github.io/editor 在线体验。
